# 文明編年史 · 開場 Hero 規格

- 署名：**Grok 4.7**（創作者，不是閘審）
- 日期：2026-10-21
- 站：world-news.xyz／本倉首頁
- 品牌：文明編年史
- 範圍：首頁開場一塊。不改 AdSense，不改新聞管線，不改監測鐘，不改開蒙樹，不上 live，不跑 wrangler。
- 原型 `prototype-index.html` 只借七句的語氣。視覺整段重做。

## 1. 敘事節拍

口吻只在這塊 Hero。溫和、短、把誇張收回來。新聞、導讀、懶人包仍是書面，文案不進 `HOME_INTRO`。

年代用「約」。畫面是示意，不是星圖，也不是地圖。氫大多來自更早的核合成，所以不說「每一個原子都在恆星核心裡待過」，只點碳、氧、鐵。

總長 **18200ms**。到點之後畫面停住，迴圈結束。

| ms | 句 | 旁白 | 畫面 |
|----|----|------|------|
| 0 | 1 | 話說，約一百三十八億年前，什麼都沒有。 | 奇點。墨底上一個紙色點，慢慢呼吸。幾乎沒有星。 |
| 2600 | 2 | 然後——「砰」。 | 砰。點輕輕張開，兩到三道細環向外走。不是白閃。 |
| 4400 | 3（旁白放輕） | 其實沒有聲音。聲音要有介質，那時還沒有。 | 仍是爆發的尾巴。這句是唯一的更正，字色改 `#c5c0b6`。 |
| 6800 | 4 | 重力把氣體收成恆星，恆星再把原子撒回太空。 | 星系。兩條旋臂轉開，內金、中紙、外冷藍。 |
| 9600 | 5 | 你身上的碳、氧、鐵，都在恆星核心裡煉過。 | 旋臂繼續，核開始讓位。 |
| 12400 | 6 | 後來有了地球。再後來，故事有了讀者。 | 地球。一顆示意圓盤：海洋、兩團紙色陸塊、一抹雲。沒有國界。 |
| 15000 | 7 | 接下來，輪到我們。時間軸就在下面。 | 接軸。圓盤下方拉出一根銅金線，末端一點，對準下面的軸。 |
| 18200 | — | 停在第 7 句 | 靜幀。`requestAnimationFrame` 停。 |

播放中一次只顯示一句。其餘句子留在 HTML 裡，但退出版面（`display: none`），所以字盒不會疊在一起。旁白區至少 4.8em，換句不把下面的鈕頂走。進來的那句在允許動態時淡入。無腳本、或系統要求減動態時，七句同時排開，不靠計時。

段落鈕：奇點（0）、砰（2600）、星系（6800）、地球（12400）、接軸（15000）。減動態時這五顆不啟播。

## 2. 視覺分鏡

整塊是欄內的墨色海報，不是另開的全螢幕站。

1. **奇點**  
   底 `#161c24`。中央紙色核，暈開銅金 `#c4a572`。角上只有極淡的塵，避免一塊死黑。沒有星海。

2. **爆炸**  
   核略張。紙色與銅金的細環向外淡出。光暈最高約 0.1 透明，不鋪滿白屏，也不閃。星從中心被放到旋臂的位置。

3. **星系**  
   扁橢圓的淡暈加上兩條旋臂。轉速約每秒 0.09 弧度量級，慢到可以讀字。內側金，外側 `#9eb8d4` 一類的冷藍。

4. **地球**  
   旋臂退到約四成。圓盤用 `#1a4a62` 海洋、`#d4c4a2` 紙色陸塊、一條薄雲、右側夜面。陸塊是橢圓，不是世界地圖。外圈一層 `#4a7fb5` 的大氣。

5. **接到軸**  
   從圓盤下緣拉一根 2px 銅金線到畫板下緣，末端紙色點。線停在畫板裡，不穿過旁白。真正的交接是按鈕「接到時間軸」，錨到既有 `#civ`。

章節色只定義在 `.bbt-hero` 上，給這塊板用，不拿去換整站皮膚：

| 代 | 變數 | 色 |
|----|------|----|
| 古 | `--era-ancient` | `#c4a572` |
| 古深 | `--era-ancient-deep` | `#9a7b4f` |
| 今 | `--era-now` | `#4a7fb5` |
| 未來 | `--era-future` | `#8d7aaa` |
| 未來光 | `--era-future-glow` | `#d5c8ea` |

紙感沿用軸上已有的做法：墨底、3px 紙點、銅金細線。禁止把頁底改成原型的 `#05060a`。

畫板無腳本時仍有一顆 CSS 紙點，所以空白畫布不是一個黑洞。腳本畫上不透明墨底之後蓋住它。

## 3. 技術選型

**用：HTML 文案 + CSS 版面 + 一個 2D canvas。**

| 方案 | 決定 | 原因 |
|------|------|------|
| 2D canvas | 採用 | 一張小畫板就能走完奇點到接軸。星數手機 96、桌面 150。裝置像素比手機封頂 1.5、桌面封頂 2。不用 `shadowBlur`。 |
| CSS | 採用 | 字、鈕、紙紋、減動態、390 寬的換行。播放中只留一句在版面上。 |
| three.js / R3F / 粒子系統 | 不用 | 簡報把這檔放在 P1，要另過動畫合議。這一版不為炫技加依賴，也不拖 LCP。 |
| gsap / lenis | 不用 | 站上已禁。滾動仍走現有的 `scrollBehavior()`。 |

迴圈只在播放中、畫板至少約 35% 留在畫面上、分頁可見時跑。播完、跳過、離開畫面、分頁隱藏，都停。沒有第二條時鐘，沒有 `setInterval`，沒有聲音。監測鐘仍是寫死的讀數。

LCP 靠 HTML 裡的品牌與第一句，不靠圖，不另載字型。Noto Serif TC 仍是全站那一份，晚到也不擋開場。

## 4. 和現有版面怎麼接

首頁順序不變，只是在軸前面加一塊：

1. 主欄目（文明｜編年｜今天｜開蒙）
2. **開場** `#opening`
3. 軸 `#civ`（唯一的首頁 h1 仍是「站在一條很長的時間軸上」；焦點頁改由焦點標題當 h1）
4. 監測鐘 `#monitor`（獨立，不接開場計時）
5. 編年帶
6. 今日落點
7. `#slice` 今日切片

實作兩處同一份字串，避免 React 把 SSR 抹掉之後開場消失：

- `shared/civilization/openingHero.ts` 的 `renderOpeningHero()`，由 `wrapCivilizationHome()` 放進首頁 SSR。
- `src/components/OpeningHero.tsx` 用同一份字串，`useLayoutEffect` 裡才啟動畫板。

開場不進文明總覽、不進 `/learn/`、不進新聞正文。開蒙仍是森羅萬象的樹。這一版不加八科捷徑卡。

「接到時間軸」指向 `#civ`。點下去用版頭高度加 16px 當 `scroll-margin`，減動態時滾動是 `auto`。無腳本時仍是普通錨點，CSS 用既有的 `--civ-anchor-offset`。

跳到今日切片的路仍在軸上，不在開場裡重複一顆黏性按鈕。開場沒有 `position: sticky`。

## 5. 手機、桌面、減動態

**手機（含寬 ≤390）**

- 開場在既有欄寬裡，左右各 −16px，對齊軸帶，不改用 `100vw`。
- 字在畫板下面，各占一列。畫板 `overflow: hidden` 只裁畫布，不裁字。
- 旁白 `overflow-wrap: anywhere`，最長句在 360 寬約兩行。播放中旁白區至少 4.8em。未顯示的句子不占位，也不和這一字盒相交。
- 段落鈕與三個控制項 `min-width` / `min-height` 44px，間距 8px，允許換行，不縮到 44 以下。
- 主鈕字 `#161c24` 在 `#c4a572` 上。旁白 `#f7f1e6`，放輕的那句 `#c5c0b6`，都在 `#161c24` 上。
- 開場 `min-height` 用 `100svh - 8.5rem`，讓第一屏是海報，但高度只是下限。減動態把七句排開時，區塊往下長，不把字裁掉。

**桌面**

- 仍在 812px 欄內。寬螢幕兩側留站上的紙色或暗色頁底，不把墨底鋪成整站。
- 畫板吃掉海報多出來的高度，地球約占短邊的 0.2。

**減動態（`prefers-reduced-motion: reduce`，以及 `body.static`）**

- 不加 `is-live`。七句一次排好。
- 「跳過開場」「重看」不顯示。
- 畫板只畫最後一幀：地球、接軸的線、停住的旋臂。沒有呼吸、沒有持續的幀迴圈。
- 透明度過渡只寫在 `no-preference` 裡；`reduce` 把開場的 `animation` 和 `transition` 關掉。

同一分頁裡播完或跳過會記下 `sessionStorage`（`wn-opening-hero=settled`）。再進首頁直接停在最後一句和靜幀，要看過程就按「重看」。新分頁仍會播。

## 6. 為什麼這不是一塊爛動畫

- 句子先排好，再讓畫面跟著走。字不浮在粒子上面。
- 動作是一條線：點、環、旋臂、圓盤、一根往下的線。播完就停。
- 爆炸被下一句收回去。沒有聲音，也沒有倒數。
- 減動態拿到的是一張完成的海報，不是停在半路的補間。
- 不換黑底，不加動畫庫，不另開靜態頁。

## 7. 已知限制

- 這一版不是 three.js。粒子大爆炸若要做，仍等 P1 合議，而且不該在這一塊上自動播放到拖死手機。
- 八科卡、橫向捲動軸、學科 modal 都不在這份裡。
- 介面切到英文時，開場仍是中文。品牌與旁白是這站的聲音。
- 地球是示意圓盤。線停在畫板底，靠按鈕接到 `#civ`，不在字上面畫線。
- 未過站級視覺閘，不得當上線許可。本 PR 不部署。

## 8. 怎麼看

```bash
npm run dev
```

打開 `/`。第一屏是開場，軸在下面。

- 減動態：系統設定或瀏覽器的 `prefers-reduced-motion: reduce`。應看到七句和一幀靜止的地球，沒有持續動畫。
- 手機：寬 360 與 390。旁白、段落鈕、三個控制項兩兩不相交，頁面不出現橫向捲軸。
- 「跳過開場」停在最後一句。「重看」從奇點再走。「接到時間軸」進 `#civ`，標題不被版頭蓋住。
