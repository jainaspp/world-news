## 1. 一句話

開場是「編年的排練」：全螢幕三幕宇宙演化（奇點→星野→行星→紫黑地平線），把全站三卷的色軸——古暖金→今冷藍→未來紫黑發光——先演一遍，最後以一枚不逐秒走動的監測讀數面板，把讀者交到今日切片與三卷手上。

## 3. 概念：排練（rehearsal)

現行上線版的哲學是「開場為序章，讓位給閱讀」；本座的哲學是**開場即編年的縮影**：讀者先在 15 秒內把整個站的閱讀法走一遍——尺度（宇宙）、位置（行星上的記錄者）、儀器（監測讀數）、目的地（三卷與今日切片）。開場不是貼在站前的動畫，而是把站的核心結構（三卷色軸）預演一次。

因此本案與三卷卡的相容不是「相鄰不衝突」而已，而是**同構**：第一幕的暖金屬於卷一「古」的色域、第二幕的冷藍屬於卷二「今」、第三幕的紫黑發光是卷三「未來」的門色。原型下方的靜態預覽（`prototype` 的 stub 段）把這一點畫出來；生產接入時該段不存在，直接接既有 `.axis-hero`／`chronicle-band`。

## 4. 敘事結構：三幕七拍

| 幕 | 拍 | 節拍時刻 | 畫面 |
| --- | --- | --- | --- |
| 一 · 深時（古暖金） | 1–4 | 0.7 / 3.0 / 5.1 / 7.4s | 奇點暖光→暖閃＋擴散環→原子湯→點燃波掃成星野 |
| 二 · 落地（今冷藍） | 5–6 | 9.7 / 11.9s | 金塵＋兩次超新星餘光→行星地平線升起、夜面城市燈火點亮 |
| 三 · 記錄者（未來紫黑發光） | 7 | 13.8s | 行星沉入地平線、底部紫黑光暈與門線展開 |
| settled | — | 15.0s | CTA、提示、監測面板、幕標軸（「古」亮起）浮現 |

旁白定稿與幽默力學見 `COPY.md`。揭示後不消失；`at` 是註冊時間不是完整閱讀時間；不鎖捲動、不攔點擊；每時段只播一次（sessionStorage）。

## 5. 視覺分鏡（全螢幕）

### 5.1 天幕（三層 CSS 漸變，`aria-hidden`、`pointer-events:none`）

| phase | 天幕狀態 |
| --- | --- |
| void／bloom／atoms／furnace | `sky-gold`：暖墨＋上中部微金霧 |
| remnant | gold 0.6／blue 0.4 交叉淡入（跨幕橋） |
| planet | `sky-blue`：冷墨＋右下冷藍暈（行星方向） |
| future／settled | `sky-future`：紫黑＋底部發光暈 |

天幕用 opacity cross-fade（1.6s，掛 no-preference），換幕無硬切；`prefers-reduced-motion: reduce` 時靜態停在最終幕。

### 5.2 canvas 圖層（單一 rAF 迴圈，各層以 τ≈480ms 指數收斂向目標）

| 圖層 | 內容 |
| --- | --- |
| 奇點 core | 中央暖光點，呼吸微脈動（拍 1） |
| 暖閃＋擴散環 | 一次性，由 `t` 確定（拍 2，3.0s） |
| 原子湯 soup | 種子粒子自中心向外鋪開（擴張的回聲），慢速漂移閃爍（拍 3） |
| 星野 stars | 種子星場；**點燃波**自中心掃開，恆星隨波亮起；之後帶視差緩慢上移（時間向前）；30% 恆星為金 `#c4a572`（拍 4 起） |
| 金塵 dust | 金星附柔光暈；兩次超新星餘光於 10.1s／10.9s 在確定性位置亮起再消散（拍 5） |
| 行星地平線 | **大半徑弧佔滿下緣**（R≈1.35h）：深墨藍夜面＋冷藍大氣緣（雙層弧線）＋沿弧聚落分佈的城市燈火（82% 暖金 `#c4a572`、18% 冷白）（拍 6） |
| 未來門線 | 行星沉出畫面，底部升起紫色徑向光暈＋自中央展開的發光門線（拍 7） |

**色值即隱喻**：第一批恆星的金與城市燈火的金是同一個 `rgba(196,165,114,*)`；監測面板的藍與行星大氣緣的藍同為 `#9ec0ef`；未來幕的紫黑是 `#2a2140` 加提議伴色 `#7e63c0` 的發光。開場的三個時代色，就是下方三卷卡的三個時代色。

### 5.3 幕標軌（底部裝飾，`aria-hidden`）

一條細軌＋「古 · 今 · 未來」三個刻名；開場播放期間，一枚金色行進點沿軌自左而右＝**開場自身的播放進度**（誠實的進度標，不是倒數鐘）；settled 時行進點抵達「古」，「古」亮起古暖金——開場把棒交給卷一。未來幕的門線就在軌的下方收尾，色相連。

## 6. 監測鐘整合（可更新的監測隱喻）

settled 時 CTA 之下浮現緊湊面板：

- **弧形鐘面**：一圈刻度＋午夜刻＋單指針停在距午夜 89 秒的位置；指針只在編輯資料更新時移動。
- **文案**：「監測 · 距午夜 一分二十九秒 · 資料日期 2025-01-28」＋「編輯寫定的監測刻度，對照公開公報；不逐秒走動。」
- **資料單源**：與 `shared/civilization/clock.ts` 的 `MONITOR_READING` 同一份值；生產接入時直接 import（原型硬編同一份值並註明）。公報更新→改一處→hero 面板、生產監測鐘、stub 預覽同步換。
- **不是恐嚇倒數**：無秒針走動、無計時器、無閃爍、無紅色；「不逐秒走動」寫在面板上；面板只在 settled 出現一次。完整監測鐘仍在生產頁原位（軸帶之後）——兩者同一資料源，不重複計時。
- **顏色**：監測屬「現在」的儀器，用今冷藍，不用紅。

與現行上線版的差異之一即在此：Kimi 座把監測鐘保持完全獨立；本座讓開場的終點**落**在監測讀數上（宇宙尺度→今日儀器），再交給軸與三卷。兩案並陳，由合議取捨（見 `NOTES-for-合議.md`）。

## 8. 技術選型與效能預算

| 項 | 決定 | 理由 |
| --- | --- | --- |
| 2D canvas（單迴圈） | 採用 | 三層天幕交給 CSS，canvas 只畫粒子與弧；與現行上線版同一技術族，合議可比、GM 可估 |
| 粒子上限 | 星 ≤230、湯 ≤140、城市燈 ≤104（依面積縮放） | 低於「每幀 500 繪製」的舒適區；DPR 封頂 2；無 `shadowBlur`（柔光全用 radialGradient） |
| 確定性 | mulberry32 種子（本座自選種子）；一次性效果由 `t` 算出 | 重播同一時刻畫面一致；審稿可截圖任何一拍（`?state=playing&t=…` 凍結幀）；與站規「無 Math.random 於元件」同一紀律 |
| CSS transition | 句子／CTA／面板／天幕換幕 | 只動 opacity/transform；全部掛 `no-preference` |
| 天幕換幕 | 三層 div opacity cross-fade（1.6s） | 全螢幕色溫演進的最低成本實現；canvas 不必畫背景 |
| WebGL／gsap／影片背景 | 不採用 | 沿用站規：P1 候選另議；零新依賴、零下載、零解碼 |
| 新 npm 依賴 | **零** | 原型＝一個 HTML 檔（約 30KB，含註釋） |

## 9. 無障礙與減動態

- 全部句子在 normal flow 由首繪佔位；揭示只改 opacity/transform——兩個文字盒**不可能**相交；CTA／提示／面板用 opacity 收起，佔位保留，CLS＝0。
- canvas 與天幕 `aria-hidden`＋`pointer-events:none`；正文全程在無障礙樹。
- `prefers-reduced-motion: reduce`：直接 settled；canvas 只畫一幀靜態完成態（星野＋紫黑門線）；CSS 另有 reduce 雙保險（`transition:none; animation:none`）。
- 跳過（播放中）／重播（settled）常駐 44×44；CTA／提示 44×44；最小字級 12px。
- 啟動保險：初次 settled→playing 翻轉掛 `boot` class 短暫停用 transition（含凍結審稿幀），杜絕「全文閃一下」與截圖落在淡出半程的窗口——這是本座在原型實測中發現並修掉的邊緣案例，生產接入時同一招。
- rAF 迴圈：IntersectionObserver 出畫面即停、分頁隱藏即停；settled 後星野與門線以極低強度呼吸（與現行上線版同一取捨；若合議要求 settled 全靜止，一個條件即可關閉）。

## 13. 原型使用方法

```bash
# 直接打開（任何瀏覽器，零網路請求）：
docs/hero-motion/glm-5p3-2026-10-23/prototype/index.html
```

## 14. 已知限制與坦白取捨

1. **開場高度高於現行版**（含監測面板：789–835px vs 703–805px）。已壓縮行距與邊距，使拍 7 與面板在 360×800 首屏內；若合議重視更短，可把監測面板改為單行緊湊版（−60px）。
2. **行星地平線的繪製成本**高於點狀地球（每幀三弧＋百餘燈點），但仍在 500 繪製預算內；低端機實測未做（接入時按 P1-PERF 走 Lighthouse）。
3. **settled 呼吸**：門線與星野低強度呼吸；合議可要求全靜止。
4. **監測面板＝第二個鐘面**：與生產監測鐘同源不重複計時，但頁面確實多一處讀數；若合議認為一處已足，可只留鐘面圖形不落文字，或整個面板回歸「只交接、不顯讀數」。
5. **幕標軌三刻名與卷名同字**：「古·今·未來」對卷一/二/三是預演也是重複標記；標籤 `aria-hidden`，無障礙上不構成噪音，視覺上是否太多，由合議定。
6. **拍 6 腳註「與第一批恆星同色」是本頁調色的事實，不是天體物理主張**（第一批恆星光譜實際偏藍）；腳註講的是「同色」這件畫面事實（見 `COPY.md` §7.6）。
7. **原型 stub 段非生產 DOM**：只為展示接駁；接入時不存在。
8. **未做 P1**：WebGL 大爆炸、互動軸、聲音——依 GM BRIEF 屬 P1，待合議。
