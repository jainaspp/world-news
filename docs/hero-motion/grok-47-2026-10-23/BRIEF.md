## 1. 一句話

**十階索引課。** 開場是一堂不鎖捲動的短課：先在墨色裡把宇宙講成一點、一聲、一捧碳和氧，然後三卷一直疊在畫面裡，十階逐級點亮。古卷暖金，今卷冷藍，未來卷是已有的紫黑填色加上一條粉筆紫縫。末日鐘不進英雄區當第二具鐘，只在未來卷頁邊寫「距午夜一分」，秒數留在下方已有的儀表。

講完，十階本身就是入口。開場要保住首屏，靠的是編年已有的十個錨點，不是落幕時新出現的三枚色票。

## 4. 圖層

畫布是裝飾（`aria-hidden`、`pointer-events: none`）。文字與十階是文件流，不用絕對定位壓字。

| 層 | 載體 | 行為 |
|---|---|---|
| `chalk` | canvas | 奇點暖點、一次紙白環、最多 56 粒粉筆星。星不畫進標題與講稿的矩形。無 `shadowBlur`，無循環閃爍。落定後停在靜幀 |
| `plates` | DOM | 三張卷。古卷無縮排，今卷與未來卷在寬螢幕各退一截，表示疊。窄螢幕不縮排，改靠左側三色脊，並把主按鈕放在三卷之上，使「開始編年」留在 360 寬度的首屏。卷與卷不互相蓋住文字 |
| `rungs` | DOM 連結 | 十階。落定前不進 Tab 序。`href` 指向 `#stage-1`…`#stage-10` |
| `mouth` | DOM | 當前主句＋旁句。換句不累積。全文在「本幕逐字」 |
| `gloss` | DOM | 未來卷頁邊。只有「一分」 |
| `hand` | DOM | 落定後的兩個按鈕與向下提示。播放中佔位但不可見，避免落定時把下方軸頂下去 |

運動語言與此前「一條線長出來」分開：主角是三卷與十階的點亮，不是一條編年線，也不是一扇會呼吸的門。

點亮用 420 毫秒的透明度過渡（只在允許動態時）。沒有指數追蹤一條曲線，也沒有 2.4 秒以下的循環。未來卷的光是恆定的內陰影，落定後不脈衝。脈衝容易被讀成警報。

畫布在英雄區離開視窗或分頁隱藏時停止。減少動態時不啟動循環，只畫落定那一幀。

## 6. 監測規則

現有 `shared/civilization/clock.ts` 的 `MONITOR_READING` 繼續是唯一讀數。原型用靜態數字演示：1 分 29 秒，日期 2025-01-28，註記原文不動。

英雄區內：

1. 單位是「分」。頁邊寫「一分」與「距午夜」，不畫圓鐘、扇形、指針或秒欄。
2. 29 秒只存在於 `#monitor` 的既有 `.bulletin-clock`。英雄區用連結「秒數見下方儀表」交出去。
3. 更新方式：編輯改 `minutes`（以及既有的 `seconds`、`asOf`、`note`）。下次載入才變。頁面上沒有會走的數字，也沒有在兩次讀數之間插值。
4. 單屏一鐘：英雄區不複製 `.bulletin-clock` 的紙色鐘面。播放時若不滾動，視窗裡沒有鐘面。
5. 紫縫深度、星點數量、卷的透明度都不讀這個數字。

禁止：逐秒走動、假精確（例如多位小數）、警報紅、警笛、對某個日期倒數、驚嚇橫幅、把讀數編成脈衝。

接線時英雄區只讀 `MONITOR_READING`，不改 `clock.ts`，不從這裡引用未來卷模組。

## 8. 播放、無障礙、減少動態

沿用已上線開場的播放政策，因為那是站的約束，不是另一席的敘事：

- 無腳本與爬蟲看到落定態：八句在逐字稿裡，十階可讀，按鈕在。
- 首次進入且允許動態：先播。`sessionStorage` 在正式站沿用現鍵 `wn_hero_seen`，避免同一節播兩次。原型用另一個鍵，免得評審被正式站的旗標卡住。
- 跳過與重播是同一顆按鈕換字，放在眉題那一行的文件流裡，不用 `position: fixed`，也不用絕對定位壓住「文明編年史」。
- 減少動態：`prefers-reduced-motion: reduce` 或原型的 `?reduce=1`。無過渡、無循環、畫布一幀、逐字稿展開。
- 句子區預留高度，十階與按鈕從第一幀就佔位，落定不把頁面往下推。
- 觸控盒至少 44×44，相鄰可點元素邊緣至少隔 8px。
- 英雄區高度沿用 `clamp(430px, 84svh, 780px)` 當下限，內容更高時整段變高，不設 `max-height`，不用 `line-clamp`。

正式站的 SSR 仍由 `shared/heroOpening.ts` 出標記，React 接手。無腳本預設落定。這是接線時的構造，原型裡用靜態 HTML 模仿，不把原型腳本搬進運行時。

## 10. 原型

`prototype/index.html` 單檔、零依賴、零外部請求。畫布粒子 ≤56，裝置像素比 ≤2。

評審定格：`?t=` 後面寫毫秒，畫面停在該時刻，不寫入已看旗標。`?t=settled` 等於落定。`?reduce=1` 強制靜態全稿。`?replay=1` 從頭播。

建議停點：`0`、`2400`、`4600`、`8080`、`11680`、`14000`、`15800`、`17200`。

定格時頂部有一行「評審定格」，只在帶 `?t=` 時出現，不進正式站。

原型裡十階與卷名的 `href` 是正式路徑。單檔打開時點擊會被攔下，並在「將前往」一行寫出路徑，避免 404。`?live=1` 關閉攔截。`#civ`、`#slice`、`#monitor` 在檔內有落點，可真的捲過去。

檔末的監測塊是 `.bulletin-clock` 的靜態複本，紙底、墨字、秒色 `#6e675c`，數字不走。接線時刪除。

`window.__HERO` 只供評審腳本讀取時刻與階段，不進生產。
