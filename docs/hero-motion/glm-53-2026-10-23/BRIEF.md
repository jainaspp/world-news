## 0. 一句話

開場是一堂開蒙講課，不是一支預告片。講者把一百三十八億年摺成一把尺；尺展開之後，就是編年頁已經在用的三卷十階。宇宙用對數環畫滿全螢幕，文明用三條橫向卷緣接上。末日鐘在這一層只出現「分」，不出現秒。

## 3. 運動規格

時間函數：環的擴張用 ease-out（約 6.4 秒走完）；卷與線用 smoothstep，窗口約 0.8 秒。原型以絕對時間直接取樣，方便 `?t=` 定格；生產接線若要指數平滑，時間常數不宜長過 480 毫秒，且定格語意必須與本表一致。

| 運動 | 規格 |
|---|---|
| 對數環 | 八個同心圓，自中心擴至視窗對角線的約 0.72 倍。環色為紙 `#f7f1e6` 低透明度，第四環為銅金。0 秒是一點，不是白閃。7.6 秒至 12 秒淡出。落定後透明度為 0 |
| 無粒子 | 不畫星野、不畫爆炸環、不畫自底緣向上長的單線。那些是另一席的語彙 |
| 尺翼 | 視窗寬於文欄時，在文欄左右兩側各畫橫線：7.2 秒暖金、11.2 秒冷藍、13.2 秒淡紫，都自左緣伸到文欄外緣。窄於文欄時不畫，避免線從字上穿過 |
| 三卷 | DOM 高度自 0 展開到內容高。階名與卷名到點即可點，不等落定 |
| 光緣 | 未來卷頂上一條 2 像素 `#c4b6e6`。播放中且該卷已展開：透明度在 0.45 與 1 之間，3.6 秒一週。落定停在 0.7。減動態不播放這條 |
| 落定 | 取消 `requestAnimationFrame`。畫布只留靜態尺翼（寬屏）或純墨底（窄屏）加上 DOM。不再呼吸、不再閃 |

減動態與 `?t=` 的優先序見 §9。減動態不是「停在第一句」，而是直接給落定靜態全文。

## 7. 監測鐘規則（分鐘隱喻）

資料來源就是 `shared/civilization/clock.ts` 的 `MONITOR_READING`（現值：1 分 29 秒，日期 `2025-01-28`，註記原文見下）。開場**不另造一個時鐘**，也不把秒抄進 Hero。

### 7.1 開場層允許顯示

- 眉題：監測
- 面：大字 `1`，單位「分餘」。`1` 綁 `minutes`。秒數不插值、不顯示
- 一行說明：距午夜的分鐘隱喻，加上資料日期
- 註記原文，一字不改：「此為編輯寫定的監測刻度，對照公開公報，並不逐秒走動。」
- 連結：「秒數與正式刻度見監測」→ `#monitor`

「分餘」是因為 29 秒是餘數，不是因為要含糊。精確的分秒留在既有 `.bulletin-clock`。開場若寫出「1 分 29 秒」，即使指針不動，也會被讀成倒數。

### 7.2 禁止

- 不逐秒走動，不畫秒針，不用 `setInterval` 改這個數字
- 不出現「29」或任何秒的數字
- 不出現「倒數」「警報」「最後」「危險」一類催促
- 不用紅色，不用閃爍紅邊，不用警鈴
- 不把光緣透明度、紫的深淺或環的速度綁到讀數
- 不假裝比公報更準（不寫小數秒）
- 頁上已有 `.bulletin-clock` 時，不第二組數字

### 7.3 單屏一鐘（接線規則）

原型頁沒有正式監測鐘，所以預設畫出紙色分鐘卡，供合議看材質：紙底、墨字、銅金只作眉題（`#7a5a32`）。

正式站首頁已有 `#monitor`。接線時改走引用，不複製數字。原型以 `?clock=refer` 演示該態：分鐘卡收起，只留一句「監測以分鐘記，不在開場重複數字。」加連結「完整刻度見監測」。

紙色是刻意的。監測是文具，和未來卷的紫光分開，也和現有 `.bulletin-clock` 的紙面同一類，而不是一扇發光儀表。

### 7.4 更新

編輯改 `MONITOR_READING.minutes` 與 `asOf`，開場的大字與日期隨之改。秒欄可以繼續只存在於 bulletin。若公報改到「不足一分」或「數分」，文案模板用「N 分餘」或「不足一分」，仍不引入秒。該模板在接線 PR 裡用資料驅動，不在本 PR 寫進 runtime。

## 9. 原型與評審定格

`prototype/index.html` 雙擊或靜態伺服器打開即可。無圖片、無字型請求、無遠端腳本。

| 查詢 | 行為 |
|---|---|
| （無） | 本節第一次：播放。播完或跳過後寫 `sessionStorage['glm53-hero-opening-seen']` |
| `?play=1` | 忽略已看旗標，重新播放（仍服從減動態） |
| `?t=毫秒` | 定格。`0 ≤ t < 16400` 為該時刻的靜止畫面，不跑動畫。`t ≥ 16400` 為落定全文。定格不寫已看旗標。例：`?t=4800` 環近滿，`?t=7200` 卷一，`?t=13200` 章門與分鐘卡 |
| `?motion=reduce` | 等同 `prefers-reduced-motion: reduce`：直接落定全文，無 rAF、無光緣動畫 |
| `?motion=full` | 評審覆寫：即使系統要求減動態，仍允許播放。正式站不提供這個開關 |
| `?clock=refer` | 正式站的單屏一鐘：不畫分鐘數字，只留引用句與連結 |
| 無 JS | 樣式預設就是落定全文，不依賴腳本才讀得到講稿 |

優先序：`?t=` 高於減動態（方便在減動態下仍抽看某一拍的靜止格），減動態高於已看旗標，已看旗標高於自動播放。`?t=` 與減動態同時存在時，畫面仍是靜止的。

播放政策：每節自動一次。重播鈕只在「曾播放或曾跳過」且非減動態時出現。系統在播放中途改為減動態，立即落定並停畫；反向不自動開播。

## 10. 已知取捨

1. 播放中只見一句。慢讀者按跳過，或等 16.4 秒，才見八句並列。減動態與無 JS 沒有這個等待。
2. 開場不印「29 秒」，和 bulletin 的面並不完全同文。這是分層，不是漏資料。正式秒數仍以 `MONITOR_READING` 為唯一真源。
3. 16.4 秒比現站 P0 的 15.6 秒長 0.8 秒，短於把十句堆在同一幕裡。長度不作為本稿的主要論點；可跳過才是。
4. 落定後對數環透明度為 0。若合議希望靜態版仍看見尺度，可把終態留在 0.2。本席預設 0，免得環和三卷搶對比。
5. 未來紫不進 `:root`。若全站未來卷要統一色，應另開 token 提案，不由開場挾帶兩枚新變數。
6. 窄屏不畫 canvas 尺翼。三卷的左緣就是尺。寬屏才在欄外加線。
