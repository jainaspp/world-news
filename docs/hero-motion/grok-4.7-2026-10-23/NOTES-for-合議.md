# 給合議的質疑清單（Grok 4.7）

這不是實作單。生產開場仍是 `shared/heroOpening.ts` 的七句、15.6 秒稿。本席的十二秒稿若被選中，才動那支檔案與 `tests/heroOpening.test.ts`。在此之前不要把預覽嵌進 `App.tsx`。

## 請美術挑戰的地方

1. **短字幕，還是現有的累積長句。** 冷開場一次只強調一句，但本提案仍讓舊句留在版面上，以免慢讀與版面跳動。若美術要「螢幕上永遠只有一句」，那些句子的盒子仍會重疊，站級閘的重疊檢查量的是盒子，不是透明度。不要用絕對定位把六句疊在同一格。
2. **地球要多大。** 現有畫布是 2.6 像素的藍點。本預覽大約 14 像素，左上方，帶一層大氣。再大就會撞上右上角的跳過按鈕，或撞進字幕。請在 360 寬上看，不要只在桌面放大。
3. **鐘會不會太像儀表。** 只有十二刻度、沒有數字、沒有秒格，是為了避開秒錶。若認不出「午夜前一分」，靠的是 `.hero-reading` 那一行字，不靠在畫布上再寫一套看不見的數字。請不要加紅色、不要加秒針、不要把刻度加到六十格。
4. **三章的顏色放在空氣裡，底邊線卻是銅金。** 金、藍、紫是三章；底邊線故意跟 `.deep-axis .rail` 用同一條漸層（透明、`#c4a572`、`#e8e4dc`、`#c4a572`、透明），這樣開場結束時線能接上軸。若改成三色線，軸上那條銅金線會斷掉。請二選一，不要兩條線同時出現。
5. **紫黑光的可見度。** `--era-future: #2a2140` 鋪在 `#161c24` 上幾乎看不出。預覽用更亮的紫做低透明度光暈，token 本身不改。請看終態底邊：光要看得見，旁白 `#a8b0ba` 仍要保持在 4.5:1 以上。不要為了「更未來」把紫鋪進正文區。
6. **金環只準一次。** 第二道環、白閃、全螢幕爆光，都會把這場開場做成片頭模板。1.5 秒、線寬 2.5px、透明度 0.62 是上限。
7. **終態要靜止。** 十二秒後星不再閃。若美術堅持星空要呼吸，請單獨開一條效能帳，不要把呼吸寫進預設。

## 請架構挑戰的地方

1. **時間軸是契約。** `tests/heroOpening.test.ts` 鎖死七句、`HERO_SETTLE_AT <= 17000`、第一句在 400ms 之後、第一句主句含「甚麼」。本稿是六句、12000ms，第一句主句仍含「甚麼」，但長度斷言會失敗。請整表替換，不要做兩套 `HERO_BEATS` 在生產裡並存。
2. **`data-chapter` 是附加屬性。** `heroPlaybackAt` 繼續以 `data-phase` 為準。採用本稿時，`soup` 可以留在型別裡直到清理，避免一次改動把階段聯合拆散。
3. **LCP。** 豁免文件 `docs/gates/reviews/2026-10-22-pr198-GM-P1-PERF-WAIVE.md` 把首頁 4.4 秒記在透明的 `h2.hero-title` 上。接回時請明文禁止：播放態不得把標題或眉題設成透明度 0，啟動腳本不得這樣做，整段英雄區也不得先整段透明再淡入。畫布延後一幀再淡入。覆核視口沿用 412×823、模擬 4G。
4. **四秒保險。** `heroBootScript` 在 React 未寫上 `data-hero-boot` 時，四秒後強制終態。這比 12 秒短，也比 15.6 秒短。無腳本的人會在中途被收到終態。請決定：保險維持四秒（開場可能播不完，但不會卡死），還是改成略大於 12 秒。不要為了播完而拿掉保險。
5. **不要從舊角度播到新角度。** 分鐘變更是發頁，不是動畫。預覽撥桿的那一下緩動只為了演示綁定。生產載入請直接畫在 `MONITOR_READING.minutes`。不要把舊分鐘存進 `localStorage` 再播一段靠近午夜的移動。
6. **秒留在原處。** `.bulletin-clock` 繼續印靜態的分與秒，文案仍是「並不逐秒走動」。開場忽略 `MONITOR_READING.seconds`。不要為了「開場不顯示秒」就把下面那只鐘改成會走的腳本。那裡的註解已經寫了沒有秒針、沒有計時器。
7. **未來章門。** `tests/chronicleVolumes.test.ts` 要求 `#ch-future` 那一段不含「距午夜」、不含 `MONITOR_READING.note`、不含 `setInterval`。本預覽的英雄文案避開了「距午夜」。請繼續避開。監測鐘自己的無障礙名稱可以維持現狀。
8. **卷卡。** 預覽在英雄區外面重複了三張 `.volume-card`，用來核對順序。生產標記仍以 `renderVolumeCards()` 為準。不要把預覽的說明段落、頁內錨點或工具列併進首頁。卷卡連結維持 `/civilization/chronicle/#ch-ancient|ch-now|ch-future`。
9. **`Escape` 跳過。** 只有在焦點不在輸入框、且開場仍在播放時。搜尋、訂閱和其他快捷鍵優先。若架構覺得多餘，刪掉不影響畫面。
10. **離屏暫停。** 預覽在英雄區不可見時暫停時間軸。生產現在用 `setTimeout`，切到背景仍會把句子補完。兩種都可以。本席偏好暫停，避免使用者回來時開場已經結束、標題以下全空過一輪。請明示選哪一種。
11. **SSR 與 React 的重播按鈕。** 伺服器標記有 `data-hero-replay`，React 元件目前沒有這個屬性。本預覽跟伺服器標記。不是這次要修的缺陷，避免接回時只改一邊。
12. **星野種子。** 預覽複製了 `heroStarRng` / `rollHeroStars` 的做法，沒有 import 生產模組，因為預覽必須單檔能開。接回時應刪掉複本，改呼叫 `shared/heroStars.ts`。高度變化不重擲這條規則請保留。

## 平庸會從哪裡進來

- 用 CSS 轉圈充當「宇宙在演化」。
- 分針每秒抖一下，或把 29 秒做成假倒數。
- 為了炫，把標題淡入，把 LCP 再做回 4 秒以上。
- 固定全螢幕遮罩，讓三張卷卡在十二秒內點不到。
- 金環連放、白屏閃爍、再加一段影片背景。
- 把這六句寫進編年正文或未來章門。
- 在生產程式裡留兩套節拍，用查詢參數切換，讓測試與無腳本終態分叉。

## 預覽自測（不是站級閘）

預覽頁把狀態放在 `window.__HERO_PREVIEW`。合議若要重跑：打開 `prototype/index.html`，看十二秒是否到 `settled` / `future` / `handoff`，跳過是否立刻到終態，減少動態是否不跑金環，分針改數字後是否停下。不要用這份靜態檔宣稱首頁 Lighthouse 已過。
