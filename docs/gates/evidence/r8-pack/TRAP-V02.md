## 允許的例外（第 3 節兩種，加上貼頂列的量法說明）

1. **父子包含。** 腳本已略過。
2. **圓點壓住 2px 軸軌。** 第二輪裡 `.axis-node`（包著圓點的整顆連結）與 `div.rail` 相交。圓點坐在軌上，連結盒子必然跨過那條 2px 線。標籤沒有彼此相交。這是第 3 節寫明的那一種，不是新的重疊。
3. **貼頂列在捲動中蓋住已經離開的內容。** 第二輪因此出現字標、搜尋、圖示按鈕、欄目晶片與當時位於視口頂部的標題或段落相交。捲回頂部之後，H／C 的正典腳本是空的。這不是首屏靜止碰撞。
4. **行內連結的聯集盒子。** 頁尾「world-news.xyz」與同一行的「重大更新」：`getBoundingClientRect` 把換行連結收成一個大矩形，看起來相交。逐行的 line box 沒有疊字。
5. **新聞相關卡的省略標題。** 最長稿與一般稿的相關卡裡，`h3.story-title` 有 `overflow: hidden` 與三行截斷。裡面的 `<a>` 還有被裁掉、沒有畫出來的行盒，聯集盒子伸進下一張卡的圖。畫出來的三行停在圖的上方（可見行底約 1103，下一張圖約 1151）。新聞頁的 `P0-CLIP` 量的是該頁 h1、主按鈕、導航晶片，不是相關卡標題。

除了上述，沒有要記的碰撞。正典腳本在靜止首屏為零。
