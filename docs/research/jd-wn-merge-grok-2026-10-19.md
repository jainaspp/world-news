## 結論

以世界頭條為唯一主軸，把 JD Tech 收成文明軸末端的實用層。終態首選是同一網域上的子路徑 `/tools/`；`/jd/` 只作短別名，不作刊頭，也不作索引名稱。

現在還不能走這一步。AdSense 重新審查的下一窗口是 2026-10-22，本倉在窗口打開前不輸出廣告單元與 `pagead` 腳本。JD 落地頁則是粵語口語、青光深色、每日兩條 Reel 的簡介連結頁，工作流庫用 StatiCrypt 加密碼，頁面卻仍然載入同一發布商的全站廣告腳本。在審查有結果、而且實用層改成書面說明之前，兩站只加軟橋。

子網域會把兩個筒倉換成同一個父網域，索引、廣告站點與部署節奏仍然分開。品牌吞併會把口語、密碼庫與 Gumroad 結帳帶進世界頭條刊頭，並一夜改寫 Instagram 與 GitHub Pages 的入口。本階段否決。

P0 不搬倉庫、不改域名、不合併網站地圖、不把密碼庫與 Prompt Pack 放進新聞站。P1 在審查有結果之後，只用三篇可整頁刪除的書面試點試 `/tools/`。P2 才把已經公開、可索引的工具網址逐條轉過來。`@rabithead1881` 與現有落地頁繼續承接舊連結。GitHub Pages 到了 P2，只把已經備好的網址逐條轉到本站，舊連結仍然打開。

## 1. 兩套產品現在各是什麼

兩套產品服務同一位香港讀者的兩件不同的事，節奏、語氣與主機都分開。

### 世界頭條

公開站是 `https://world-news.xyz`。本倉的正式部署方向是 Cloudflare Pages。頁面只列公開報道的標題、來源、時間與原文連結，不轉載全文。其上另有導讀、懶人包、文明軸、當年今日與香港地標。

文明軸的順序是宇宙、地球生命、人類起源、技術、城市、今天。今天的新聞是軸上的切片，不是另一套文明。技術頁沿「工具、能源、媒介、知識」四線書寫，並把今日科技報道交回軸的末端：一則電訊通常只落在其中一至兩條線。近層切片已經用「今日可問」連回軸上先例；對不上主題的懶人包不出現切片，空欄不渲染。

書面語是站內正文的語體。視覺是紙感版面與襯線標題；文明層使用墨色 `#161c24`。新聞版面的主色是 `#1d4f91`，底色 `#f4f6f8`。導讀在香港時間 07:30 與 18:30 各一篇。

廣告政策寫在 `shared/adPolicy.ts`：`ADS_REVIEW_HOLD` 為真，下一審查窗口 2026-10-22。凍結期間即使配置了版位，也不輸出廣告單元與載入腳本。窗口之後的第一步，仍只在可索引、正文足夠的頁面放手動版位，自動廣告維持關閉。`public/ads.txt` 是：

`google.com, pub-8392975944327076, DIRECT, f08c47fec0942fa0`

`/compare/` 已經 301 到 `/explainer/`。`/about/` 與 `/privacy/` 是本站的關於與私隱頁。

### JD Tech

倉庫是 [jainaspp/jd-tech-landing](https://github.com/jainaspp/jd-tech-landing)，GitHub Pages 由 `main` 的網站根目錄直接發布，沒有建置步驟。公開位址是 `https://jainaspp.github.io/jd-tech-landing/`。README 仍只列出首頁、新手入門與 Prompt 三步；當日網站地圖已有 95 條網址，README 落後於線上結構。

它是 Instagram `@rabithead1881` 的簡介連結頁，不是新聞產品。首頁標題是「粵語 AI 日更｜免費工具 3 步實測」，說明每日約 07:00 與 12:00（香港時間）更新。版面是手機優先，最大寬度約 440 像素，底色 `#0A0A0A`，強調色 `#00E5FF`。正文是粵語口語。

當日網站地圖的構成：

| 目錄 | 條數 | 角色 |
| --- | --- | --- |
| `/reels/` | 60 | 單條 Reel 的跟做頁 |
| `/learn/` | 11 | 免費教學 |
| `/tools/` | 11 | 工具目錄與單工具頁 |
| `/compare/` | 3 | 工具對照 |
| 其餘 | 各 1 至 2 | 新手、Prompt、Prompt 組裝、香港 Prompt、更新、關於、私隱、休閒 |

首頁公開點名的工作流包括 Canva、Copilot、改履歷、Gamma、Notta，並寫「全部 15 個」。場景包括返工、求職、租樓、學生、小生意、政府表格。`/workflow/` 用 StatiCrypt 在瀏覽器內解密，標題作「會員通道」，`robots` 為 `noindex, nofollow`，且不進網站地圖。密碼 `jdtech3` 同時出現在首頁說明、meta description 與錯誤提示裡，所以這是公開的軟閘，不是秘密。

關於頁寫明：帳號不隸屬各工具供應商；不賣課程、不收代操；網站上的教學與三十條 prompt 免費。唯一收費是 Gumroad 上的《香港實戰 AI Prompt Pack》（頁面標價 HK$10.40，另有六條免費試用）。關於頁又寫「現在網站沒有廣告」，其後可能以明確披露的方式加聯盟連結。

同一日的 HTML 與此句不一致：首頁、工具目錄、關於頁、私隱頁，以及 `noindex` 的工作流閘門，都載入

`pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-8392975944327076`

抽查這些頁面沒有看到 `<ins>` 手動版位。腳本是否實際播出自動廣告，取決於 AdSense 控制台，本文件不能代為確認。`ads.txt` 放在專案路徑 `/jd-tech-landing/ads.txt`。AdSense 讀取的是主機根目錄；`jainaspp.github.io` 的根目錄不由這個倉庫控制。倉庫裡的 `robots.txt` 也註明：爬蟲只會在檔案位於 `https://jainaspp.github.io/robots.txt` 時套用該規則。

兩站已經共用發布商編號 `pub-8392975944327076`。共用範圍停在廣告帳號。產品、主機與語體仍然分開。

## 2. 為什麼新聞站必須是主軸

JD Tech 擅長取得注意：每日兩條短片、三步可抄、簡介連結、一頁裡收齊當日入口。世界頭條擅長把一件事放回一條可以重讀的軸：來源可核對、書面語、紙墨語氣、審查與合規都已經長在這個網域上。

主軸放在新聞站，是因為四件事只有這邊同時成立。

1. 網域由自己控制。`world-news.xyz` 的 `ads.txt`、`robots.txt` 與網站地圖都在主機根目錄。GitHub Pages 的專案站做不到。
2. 資訊架構已經能容納「今天」。技術頁的末端就是今日切片，近層橋已經規定空的對照不渲染。實用層是這座橋的下一格，不是新的文明階段。
3. 信任機器已經在跑。正文不足不進索引、不放廣告；香港與內地桌有來源邊界。這些規則不該為了工具目錄改寫。
4. 落地頁的價值在於快。把它升格為刊頭，新聞站會變成另一個簡介連結頁，文明軸會變成裝飾。

因此 JD 繼續做取得注意的引擎。世界頭條做讀者留下之後的那一層：這件工具落在哪一條線，今天的報道在問什麼，步驟是否仍與官方說明相符。

## 3. 選項譜系

排序按「新聞站是唯一主軸、漏斗相通、做了還能拆開」計算。這個排序量的是終態是否合適。施工順序見第 6 節：現在只做軟橋。終態第一的方案，現在不做。

| 順位 | 方案 | 主軸是否在新聞網域 | 筒倉是否還在 | 可逆性 | 本階段 |
| --- | --- | --- | --- | --- | --- |
| 1 | 子路徑 `/tools/`，`/jd/` 只作別名 | 是 | 公開工具頁可收進同一站 | 刪目錄、撤轉址即可 | 終態；P1 起試點 |
| 2 | 軟橋 | 是，但工具仍在站外 | 兩座站仍在，只是互相指向 | 刪連結即可 | 現在 |
| 3 | 子網域 | 父名可見，網址仍是第二站 | 仍在 | 刪 DNS 即可 | 不採用 |
| 4 | 品牌吞併 | 刊頭被第二品牌改寫 | 表面合成，語氣分裂 | 難 | 否決 |

### 3.1 子路徑 `/tools/`（終態首選）

公開的工具說明放在 `https://world-news.xyz/tools/` 與其下的單頁。`/jd/` 若需要短連結，只做 301 或 302 到 `/tools/`，不寫進網站地圖，頁面標題仍是世界頭條的實用層，不出現第二個站名當主標題。

選 `/tools/` 而不是以 `/jd/` 為正式路徑，有三個原因。

- JD 自己的公開目錄已經叫 `/tools/`。日後逐條轉址時，`/tools/canva/` 可以對上 `.../jd-tech-landing/tools/canva/`。
- 「工具」對得上技術頁的四線用語。讀者看到的是軸上的一格，署名可以仍是 JD Tech。
- `/jd/` 作正式路徑，會在新聞網域上再立一個品牌首頁。那是較溫和的吞併，仍然拆主軸。

這一層的正文用書面語，標明步驟對應的公開功能與核對日期，並連回官方說明。視覺沿用本站紙感與墨色，加一枚「實用」印，與編年、地標分開。不搬青光深色，不把版面收成 440 像素的簡介連結頁。

子路徑同時解決主機根目錄的 `ads.txt` 問題：頁面若將來符合本站廣告規則，才可能使用已經放在 `world-news.xyz/ads.txt` 的那一行。這不是現在加廣告的理由。試點頁在 P1 不放廣告。

落地頁使用相對連結，並且要在 `/jd-tech-landing/` 這個前綴下運作。不能把倉庫原樣抄進本站根目錄。

### 3.2 軟橋（現在就做的那一級）

兩座主機、兩個倉庫、兩套發布都保持原狀。只加互相指向的連結，並用 UTM 分辨人從哪裡來。

建議的出口只有兩處，而且都是一句話，不是欄目。

- 自 JD 落地頁與 Reel 文案，加一條「想看這件工具今天落在哪一條報道線」，連到 `https://world-news.xyz/civilization/tech/` 或當日科技財經導讀。不要連到首頁，也不要連到地區頁。
- 自世界頭條技術頁末端，或與「語音影像、學習知識傳播、計算工具」對得上的切片，加一條「口語示範仍在 JD Tech」，連到現有落地頁的對應公開頁。對不上就不出現。

Instagram 簡介連結的主網址維持現有落地頁。世界頭條只作第二句，或不出現在簡介連結裡，直到 `/tools/` 能夠在一擊之內交出「當日 Reel、免費教學、工作流入口」這三件落地頁今天已經交出的事。

軟橋的限度要寫清楚：人還是要跨站，工作階段對不上，廣告與結帳仍然分家。它是走向子路徑的台階，本身還不是合併。

### 3.3 子網域（不採用）

`tools.world-news.xyz` 或 `jd.world-news.xyz` 能讓父品牌出現在網址上，部署也可以繼續獨立。對本目標沒有幫助。

搜尋與廣告系統通常把子網域看成另一個站點。`ads.txt` 要在該主機根目錄再放一次，審查邊界也再裂開一次。讀者、語氣與發布節奏仍然是兩個筒倉，只是漆了同一個父名。可逆不等於值得做。獨立部署這個好處，用「內容仍留在 JD 倉庫、由本站只讀引用或稍後逐頁搬」就能保留，不必另開主機。

### 3.4 品牌吞併（本階段否決）

否決的做法包括：把刊頭改成 JD Tech 或雙品牌、用青光深色重做世界頭條、用粵語口語重寫軸頁、讓簡介連結一夜改到新聞首頁、關閉 GitHub Pages、把密碼庫與 Gumroad 放進首頁或文明頁。

這些做法會同時碰觸三條已經寫明的邊界：文明軸的書面語氣、審查凍結，以及「不要一夜切斷 Instagram 與落地頁的流量」。

## 4. 讀者旅程

兩條旅程都沿着同一條軸走，方向相反。新聞頁不播放 Reel，Reel 也不改成新聞腔。中間用一頁書面說明交接。

口語留在 Instagram 與現有落地頁。進世界頭條的只是書面轉寫：這件工具做什麼、三步如何操作、哪裡要自己核對、官方說明在哪裡。密碼、標價與「跟住抄」不進軸頁。

### 4.1 新聞讀者到工具或 Reel

讀者此時要的是：這則報道裡的能力，今天能不能做一次。

1. 入口只放在已經與工具有關的頁：`/civilization/tech/` 的末端、科技分類或科技財經導讀、以及近層主題「語音影像」「學習知識傳播」「計算工具」。首頁刊頭、宇宙、地球、起源、城市編年、地標、地區與分類桌不放入口。
2. 模組沿用近層橋的規矩，名稱用「今日可做」。先寫機制，再給一頁書面說明。例：一段錄音如何留下可核對的紀要，然後才是某一件紀錄工具的三步。對不上主題、或說明尚未寫成，模組不渲染。
3. 書面頁本身不嵌影片、不彈密碼、不放結帳。頁末單獨一行「口語示範」，標明將離開本站，開到對應的 Instagram Reel 或現有落地頁。
4. 返回路徑回到軸錨或該則切片，不把讀者送進十五個工作流的目錄。

### 4.2 Reel 或工具讀者到新聞

讀者此時要的是「我剛剛照着做的這件事，今天的報道在說什麼」。不要把他們倒進首頁。

1. Reel 仍在 Instagram 發布。片尾與簡介連結繼續以現有落地頁為主擊，直到 P2 的工具索引能接住同一擊。
2. 落地頁加一句書面的上行連結，連到技術頁或當日科技導讀。連結文字說明目的，不把世界頭條寫成第二個口號。
3. P1 之後，試點頁可以成為個別 Reel 的試驗出口。簡介連結主網址仍然是落地頁。同一則內容不要有兩個自訂 canonical。
4. 上行的第一落點是工具說明或技術軸末端。不把 Reel 流量送進 `/`、`/region/` 或宇宙長河。短片流量的跳出若發生在首頁，既傷害閱讀，也給審查中的站點帶進一批與新聞無關的工作階段。

### 4.3 對得上與對不上

| 可以上軸 | 留在 JD |
| --- | --- |
| 紀錄與轉寫（對齊語音影像） | 改履歷、辭職信、宴會請柬 |
| 帶來源的核對（對齊可核對的記錄） | 政府表格、租樓程序 |
| 把一份文件整理成可重讀的說明（對齊知識傳播） | 休閒區遊戲、換裝、去背等單次技巧 |
| 簡報只作為「媒介如何把一份說明交出去」的一個例子，且必須連回來源 | 十五個加密工作流的原文 |

空的對照不製造新主題。近層橋已規定：對不上現有模式，就不要新造編號。實用層遵守同一條。

## 5. P0 不合併的部分

P0 的定義是：除了本文件與日後各自站上的一條外鏈，系統現狀保持不變。下列項目即使在 P2 也不整包合併；標了「永不」的，不因為試點成功就重新打開。

| 項目 | 理由 | 期限 |
| --- | --- | --- |
| 兩個倉庫與兩套發布 | Cloudflare Pages 與 GitHub Pages 的節奏不同；相對連結不能整倉搬入 | 至少到 P2 逐頁之前 |
| 視覺系統 | 紙墨與青光深色是兩種產品。實用層若進本站，用本站紙感，不改造新聞版 | 實用層可用紙感；青光不進本站 |
| 語體 | 軸頁維持書面語。粵語口語留在 Reel 與落地頁 | 持續 |
| 發布節奏 | 導讀 07:30／18:30，Reel 約 07:00／12:00。合成日曆會逼新聞桌追短片，或逼短片改成早晚報 | 持續 |
| 刊頭與站名 | 站名維持世界頭條 | 永不在本階段改 |
| Instagram 帳號與簡介連結主網址 | 流量入口。主網址在工具索引能接住三項任務之前不改 | 至少到 P2 |
| `/workflow/` 密碼庫 | StatiCrypt、`noindex`，密碼公開。不解密進本倉，不放進網站地圖 | 持續留在 JD |
| Gumroad Prompt Pack | 買家是短片觀眾。結帳留在站外 | 可不進新聞正文 |
| 全站 `adsbygoogle.js` | 審查凍結禁止本站載入；JD 閘門頁亦不宜作為範本 | P1 試點頁不放廣告 |
| 網站地圖與 canonical | 避免兩套重複頁同時被索引 | 到逐條轉址之前 |
| `/compare/`、`/about/`、`/privacy/` | 本站 `/compare/` 已轉到懶人包；關於與私隱是新聞站的法律頁 | 工具對照若要存在，放在 `/tools/compare/`，不佔用 `/compare/` |

## 6. P0 至 P2

每一級都要能在不關 Instagram、不關落地頁的情況下撤回。通過條件用可以觀察的事實，不用日曆承諾。

### P0　軟橋，主機不動

做這些：

- 以本文件為合併邊界。不改本倉的頁面、路由與廣告開關。
- 若在 JD 倉庫加上行連結，只加一條，連到技術頁或當日科技導讀。簡介連結主網址不變。
- 若在本站加下行連結，只加在第 4.1 節的入口，對不上不渲染，並標明離開本站。
- 連結帶 UTM：`utm_source` 用 `jd-ig`、`jd-landing` 或 `wn-tech`，`utm_medium=bridge`，`utm_campaign=tools-2026-10`。
- 由帳號主人在 AdSense 控制台確認：重新審查窗口前後，自動廣告是否關閉；JD 頁面上的腳本與關於頁「現在沒有廣告」是否要先改成一致。本倉不能替控制台做這件事。

不做第 5 節的任何一項。

可以進入 P1 的條件：審查窗口已有結果並記在本倉的廣告政策旁；軟橋沒有把工具流量送進首頁；帳號沒有因為 JD 頁面收到政策警告。若審查未過，停在 P0，繼續分開兩座站。

撤回：刪掉那一條連結。沒有 DNS、沒有轉址、沒有要恢復的索引。

### P1　三篇書面試點

只寫三篇新的書面說明，不複製粵語頁，以免兩套 canonical 互相打架。

| 試點 | 對齊的既有近層 | 不寫進去的東西 |
| --- | --- | --- |
| 錄音如何變成可核對的紀要 | 語音影像 | 不嵌 Reel，不抄密碼庫 |
| 回答如何帶着來源被事後核對 | 可核對的記錄 | 不比較廠商排名 |
| 一份文件如何讓陌生人重讀 | 學習知識傳播 | 不把簡報工具寫成主體 |

路徑用 `/tools/<slug>/`。正文用書面語，寫明核對日期與官方說明。索引名稱是「實用」，印記與編年分開。`/jd/` 此階段可以不做；若做，只轉到 `/tools/`，且不進網站地圖。

試點頁不放廣告單元，也不載入 `pagead` 腳本，即使審查已經通過。審查通過後的第一批廣告仍只放在原有、符合字數與索引規則的新聞頁。

GitHub Pages 上的對應頁保持原 canonical，繼續服務。本站試點是平行的書面版，不在 P1 對舊網址做 301。

可以進入 P2 的條件：三頁都能整頁刪掉而網站其餘部分不受影響；語氣抽查沒有粵語口語、密碼與標價；沒有被放進地區桌或文明階段正文；廣告帳號沒有新的政策警告。任一條不成立，就停在這三頁或刪掉它們。

撤回：刪掉這三個路由與入口連結。Instagram 從未把這三頁當成唯一出口，所以舊流量仍落在落地頁。

### P2　逐條把公開頁接過來

只轉移已經公開、可索引、並且改寫成書面語的工具頁與教學頁。順序是：先在 `/tools/` 備好對應頁，確認一擊之內能看到當日入口，再把該條 GitHub Pages 網址 301 過來。

同時要做的事：

- 工具索引要能接住落地頁今天的三項任務：當日 Reel 的書面入口、免費教學目錄、前往工作流的說明。工作流本體仍留在 JD 的 `/workflow/`，本站只說明「完整可抄流程仍在原處」，不把加密頁搬過來。
- 簡介連結可以把主網址改到 `https://world-news.xyz/tools/`，但舊的 GitHub Pages 網址必須已經逐條轉址，已發出的 Reel 才不會斷。
- Prompt Pack 仍以站外 Gumroad 連結出現在工具索引的「延伸」裡，不出現在首頁、導讀與文明頁。
- 工具說明若將來要廣告，單獨適用本站規則：可索引、正文足夠、手動版位、自動廣告關閉。未達標的頁不為了變現而加腳本。
- 視覺維持紙感與「實用」印。站名仍是世界頭條。JD Tech 可以作為這一層的署名與 Instagram 名稱，不作為第二個刊頭。

撤回的單位是單條網址：拿掉該條 301，讓 GitHub Pages 重新自己回應，並把簡介連結主網址改回落地頁。不要用一次全站切換。

`/workflow/`、休閒頁、政府表格與租樓等程序頁不在 P2 的轉移名單裡。

共用的是讀者的下一步。收銀臺仍然分開。

        │ 主擊，P2 之前不變
        ▼

子路徑對變現的真正好處，是讓將來合法的展示廣告使用自己網域根目錄的 `ads.txt`，而不是 `github.io` 專案路徑下那一份爬蟲不會當成主機根目錄讀取的檔案。這個好處在審查完成、頁面達標之後才存在。為了這個好處提前搬頁，會把密碼閘、口語薄頁與全站腳本帶進正在受審的站。

短片是取得注意的便宜入口，新聞軸是留下的理由，Prompt Pack 是已經願意照着做的人的小額購買。三件事串在一條路上，帳分開記。P0 只用 UTM 看人有沒有走上行或下行，不合併分析後台。

## 8. 審查、路徑與內容邊界

## 9. 停損

出現下列任一情況，停在當前一級並撤回該級新增的連結或頁面。Instagram 與落地頁保持可開啟。

- 審查未過，或帳號出現與工具頁、密碼閘、自動廣告有關的政策警告。
- 工具流量被送進新聞首頁、地區頁或文明階段正文。
- 書面頁出現口語推銷、密碼、標價，或與落地頁重複到必須爭奪 canonical。
- 為了填滿 `/tools/` 而把對不上近層的生活行政頁搬進來。
- 簡介連結主網址已改，但新頁還不能在一擊內交出當日 Reel、教學目錄與工作流入口。

停損之後的穩定狀態，就是今天已經在運作的狀態：世界頭條繼續做文明軸與今日切片，JD Tech 繼續做 Reel 與落地頁，中間最多留一條軟橋。
