# Z08 · 《文明進度盤》

- **id：** Z08
- **title：** 文明進度盤
- **one_liner：** 全站是一座十界棋盤式的文明進度盤：使用者持一本文明護照逐域蓋章推進，新聞是每日戰報，開蒙是護照內的任務徽章系統——讀文明、解任務、集滿十域即達「全景印記」。

## 結論先行

本案把「由淺入深、解鎖下一級」的開蒙機制推廣為全站機制：使用者三十秒內理解「這是一張文明進度盤，我在收集對整部文明史的理解」。護照與印章提供明確的回訪鉤子；新聞被重塑為「今日戰報」的任務化薄層；開蒙與敘事共用同一套徽章資料層，擴容即加域。與前七案的觀照式骨架不同，本案的獨特貢獻是遊戲化的全域進度敘事。

## sitemap

```
/                      進度盤全景（十域棋盤＋護照入口）
/realm/{n}/            域頁（n=1–10：厚文＋域內印章任務）
/report/today/         今日戰報（新聞切片，日更）
/passport/             我的文明護照（全域進度與徽章牆）
/quests/{track}/       任務線（開蒙學科樹總覽）
/quests/{track}/{tier}/  任務階（由淕入深，逐階解鎖）
/quests/{track}/{tier}/{quest}/  單任務卡（作答蓋章）
/herald/               傳令室（合規、CC BY 4.0、關於）
```

## home_wire

1. 首屏進度盤：一張俯視十域棋盤在暗場中逐格點亮的開場動畫（演化縮時以盤面格序重演），旁白一句幽默科普（「十格棋盤，下完四十億年」）。
2. 護照攤開一角：全域進度環與已集印章縮影。
3. 今日戰報箋：盤側一枚火漆封緘的日更小報。
4. 任務線入口：三條學科任務線與當前階位。
5. 傳令室頁腳。

## nav

- 頂部：盤徽＋護照按鈕（常駐個人狀態）。
- 側部（桌面）：盤緣目錄——十域環列，古域暖金格、今域冷藍格、未來域紫黑發光格。
- 底部（390）：五枚印章鈕——盤／域（最近）／戰報／任務／護照。

## mobile

390 寬以「點格落子」為核心：棋盤格以卡池縱列呈現，點按即入域；域內閱讀為直式；作答介面為底部浮層選項卡，答對觸發蓋章動畫（震動＋印章落紙）；護照頁為橫滑徽章牆；今日戰報為單欄任務化日更（每則新聞附一枚可完成的輕任務）。

## visual

- 色區：棋氈近黑基底；古域暖金漆格、今域冷藍瓷格、未來域紫黑霓虹格；印章與徽章統一硃紅，作為跨三卷的功能色。
- 字階：域題 26px 印刷體、內文 17px、戰報標題 15px。
- 動效三層：L1 點盤開場（僅首訪）；L2 蓋章與徽章落紙（互動觸發，回饋向）；L3 域頁內圖版逐格翻面（捲動觸發）。全 CSS 變換，無遊戲引擎。

## rebuild

1. 殼：進度盤路由與格序資料層、護照狀態模型（localStorage 先行，後帳戶）。
2. 模板：域頁、戰報頁、任務卡三模板。
3. 開蒙：任務線資料層與域章聯動、作答引擎。
4. 內容：十域厚文與域內輕任務撰寫。
5. 上線閘：無帳號可完整體驗主線（不強制註冊）、減動效模式、傳令室合規頁與授權標示。

## risk

1. 遊戲化反噬：對純閱讀者，任務與蓋章可能構成干擾——閱讀路徑必須可完全繞過任務系統。
2. LCP：盤面與動效若先於內容，首屏將空轉——域頁必須可被搜尋引擎直接收錄（預渲染）。
3. 進度持久化：無帳號即 localStorage 一旦清空即歸零，需明示進度說明並提供匯出，否則信任流失。
