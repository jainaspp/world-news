# Z02 · 《十界星圖》

- **id：** Z02
- **title：** 十界星圖
- **one_liner：** 全站不是一疊頁面，而是一張可平移縮放的深空星圖：十階文明是十座星系，今日新聞是圖上唯一的觀測站，開蒙是逐星系點亮的登陸圖鑑。

## 結論先行

本案把資訊架構從「文件樹」換成「空間地圖」：使用者三十秒內理解「我在一張宇宙地圖上，暖金區是過去、冷藍區是現在、紫黑區是未來」。主敘事由空間方位承載，探索感即品牌感；新聞被收束為單一「觀測站」浮標；開蒙以「登陸任務＋圖鑑」形式可無限擴張。與 Z01 的閱讀器不同，本案賣的是可導航的宇宙本體。

## sitemap

```
/                     星圖（全站本體，可分享錨點 #galaxy-{n}）
/beacon/              今日觀測站（新聞切片，日更）
/galaxy/{n}/          星系頁（n=1–10，預渲染落地的厚文頁）
/codex/               圖鑑（開蒙學科樹總覽＋解鎖進度）
/codex/{track}/       學程
/codex/{track}/{level}/  登陸任務卡（答對解鎖下一級）
/marginalia/          圖邊注（合規、CC BY 4.0、關於）
```

新聞站皮徹底退場：不再有 region/category 路由，全部併入觀測站單頁分籤。

## home_wire

1. 首屏即星圖：載入時播放一次「點燈」序列——宇宙由暗到亮、十座星系依序浮現（即 BBT 式演化開場），完結後「今」星系脈動引導。
2. 觀測站浮標在冷藍區閃爍，旁標「今日觀測已更新」。
3. 右緣圖鑑側欄常駐一角：進度環＋三學科入口。
4. 底部膠囊列：十星系快速定位（可橫滑）。
5. 圖邊注折角。

## nav

- 無傳統頂欄：HUD 化——左上落款印、右下縮放與指北控件、底部星系膠囊列、右緣圖鑑側欄（可收）。
- 觀測站與星系頁保留極簡回航鈕「返回星圖」。

## mobile

390 寬：單指拖曳平移、雙指縮放星圖；雙擊回中。底部膠囊列代替頂欄切星系；星系頁以全螢幕卡呈現，下滑手勢關閉返回星圖；觀測站為直式單欄日更列表；圖鑑側欄在行動端變為底部第二層抽屜。

## visual

- 色區：深空黑基底；星雲三帶——外緣暖金（古）、中央冷藍（今）、遠端紫黑發光（未來）；三帶不規則銜接。
- 字階：HUD 用小號寬字距無襯線（12–13px），星系頁內文 17px。
- 動效三層：L1 點燈開場（僅首訪）；L2 星系常態微光與浮標脈衝（CSS animation）；L3 星系頁內滾動視差（捲動觸發）。canvas 僅做靜態星場＋transform，粒子數量設上限。

## rebuild

1. 殼：星圖畫布引擎選型（優先 SVG＋CSS transform，互動重時再評 PixiJS），路由與錨點系統。
2. 落地：十座星系頁預渲染模板（SEO 與 LCP 的生命線）＋骨架屏。
3. 觀測站：新聞切片單頁（資料層沿用，模板全新）。
4. 圖鑑：學科樹資料層、登陸任務答題引擎、解鎖狀態。
5. 上線閘：無 JS 環境可讀星系頁、行動手勢與瀏覽器衝突覆核、合規頁與授權標示。

## risk

1. LCP／SEO：純 canvas 首屏無文字可渲染——必須以預渲染星系頁與疊層文字保底，否則搜尋收錄與效能雙輸。
2. 手勢衝突：平移縮放與瀏覽器手勢、橫滑返回易打架，需手動鎖定 touch-action 並全機型覆核。
3. 空間過載：十星系若內容稀薄，地圖會暴露空曠感；上線閘應設「每星系至少一厚文＋一任務」。
