# Z01 · 《千年三卷》

- **id：** Z01
- **title：** 千年三卷
- **one_liner：** 把全站做成一部可翻閱的三卷巨著：洪荒卷、煙火卷、星塵卷，新聞只是夾在卷二的「今日一頁」插頁，開蒙是卷末由淺入深的注疏學程。

## 結論先行

本案將文明編年史徹底「書化」：使用者三十秒內看到的是一張書封、三條書脊、一句落款，理解「這是一部從宇宙洪荒寫到星際未來的編年史」。閱讀是最古老的長形式，天然承載厚文；新聞被降格為書中插頁，不再定義品牌；開蒙以「注疏」形態內嵌於每一章，可無限擴容。相對其他各案，本案的獨特貢獻是「閱讀器產品」：版面即書頁，動效即翻頁。

## sitemap

```

/vol/ancient/{stage}/  章頁（厚文＋插畫＋注疏錨點）
/vol/present/          卷二・煙火（目錄頁，第 5–7 階）
/vol/present/today/    今日一頁（新聞切片，日更插頁）
/vol/present/{stage}/  章頁
/vol/future/           卷三・星塵（目錄頁，第 8–10 階）
/vol/future/{stage}/   章頁
/annotations/          注疏總目（開蒙學科樹入口）
/annotations/{track}/  學程（如「天文」「材料」「城市」）
/annotations/{track}/{level}/  注疏卡（答題解鎖下一級）
/colophon/             版權頁（CC BY 4.0 聲明、關於本書、合規總覽）
/search/               全書檢索
```

舊路由 cosmos／earth／origins 等全部整併為章頁，不保留舊契約。

## home_wire

1. 首屏書封：暗場中一次「開卷」序列——宇宙縮時演化動畫收束為一滴金色墨點，墨點暈開成本書書名（幽默旁白一句，如「四十億年，濃縮成三卷」），提供「跳過開場」。
2. 三卷書脊橫列：卷一暖金、卷二冷藍、卷三紫黑，hover／點按即推開封面一角預覽目錄。
3. 今日一頁插頁預告：一張窄幅日曆箋，寫「卷二・今日一頁已送達」。
4. 注疏學程帶：橫向列出三個學科入口與當前解鎖進度。
5. 版權頁腳：授權、關於、檢索。

## nav

- 頂部：極簡書眉——左「文明編年史」落款印，右為檢索與注疏入口。
- 側部：常駐三卷書脊（桌面直立於左緣，點按切卷）；卷內「箋條」目錄為抽屜。
- 底部（390 主要導航）：四枚書籤籤標——三卷／今日／注疏／檢索。

## mobile

390 寬以直式長卷閱讀為核心：上下滑動即翻「簡」，章內段落以卡片節奏分段；卷切換走底部書籤籤標，章目錄為上拉抽屜；注疏錨點為行內藍色小鈕，點開即底部浮層卡，不打斷閱讀軸。今日一頁為單欄插頁排版。

## visual

- 色區：卷一暖金（墨金 #B8860B 系）、卷二冷藍（青藍 #2C5F8A 系）、卷三紫黑發光（#6B4FA0 系）；基底為紙白與墨黑雙主題。
- 字階：內文 17px 宋明體系統字、章題 28px、書名 40px；行距 1.9。
- 動效三層：L0 頁面淡入淡出（全部轉場）；L1 開卷動畫（僅書封首次）；L2 章內插畫視差與墨點暈染（捲動觸發，IntersectionObserver，無依賴大庫）。

## rebuild

1. 殼：三卷路由骨架＋書封開卷序列（改造既有 HeroOpening 為「開卷」，控制 CSS 動畫預算）。
2. 模板：章頁（厚文）模板、今日一頁模板、注疏卡模板。
3. 內容：舊 cosmos／earth／origins 厚文整併為卷一各章，第 5–10 階補寫。
4. 開蒙：注疏資料層——學科樹 JSON、解鎖狀態（先 localStorage，後帳戶）。
5. 上線閘：首屏文字先行渲染驗證、無障礙閱讀模式、版權頁與 CC BY 4.0 標示、零政治內容覆核。

## risk

1. LCP：開卷動畫若阻塞首屏文字將直接超標——動畫必須疊層於已渲染文字之上並可跳過。
2. 內容厚度：「書」的承諾要求每章皆有實文，若僅有骨架易淪為空殼書；上線閘應設「每卷至少三章足文」。
3. 新聞存在感過低影響今日一頁回訪與廣告版位，需以日更箋條推送補償。
