# Z06 · 《文明檔案館》

- **id：** Z06
- **title：** 文明檔案館
- **one_liner：** 全站是一座夜間開放的檔案館：十階文明是十冊編號證物卷宗，新聞是每日「入藏登記簿」，開蒙是「研究員養成階梯」——從見習生一路升到館員，每級解鎖更深密室。

## 結論先行

本案以「機構」取代「媒介」：使用者三十秒內理解「這裡收藏文明的證據，我是來查檔的」。卷宗天然承載厚文與出處（與 CC BY 4.0 的引註文化同構）；新聞被收編為入藏登記的行政薄層；開蒙被敘事化為研究員升等制度，升級即開啟新密室，擴容即擴館。與前五案的「自然物」骨架不同，本案提供的是制度感與收藏感，最利於建立權威與長期回訪。

## sitemap

```

/reading-room/         閱覽室（主題選輯：跨卷宗懶人包）
/intake/               入藏登記簿（新聞切片，日更）
/academy/              研究員養成階梯（開蒙學科樹總覽）
/academy/{track}/      學科梯（見習→館員各級）
/academy/{track}/{rank}/  階級考核卡（答題升等）
/vault-future/         未來密室（第 8–10 階內容，隨等級解鎖）
/colophon/             館務室（合規、CC BY 4.0、關於本館）
/finding/              檢索目錄（全館查檢）
```

## home_wire

1. 首屏檔案館大廳：射燈逐盞亮起的開場（一冊冊卷宗被推上長桌），旁白一句幽默科普（「宇宙的第一份檔案，編號 001」）。
2. 館藏十卷宗：以檔案排架呈現，古段暖金標籤、今段冷藍標籤、未來密室紫黑上鎖。
3. 入藏登記簿：櫃檯側一本日更登記冊，「今日新入藏」。
4. 研究員階梯入口：一枚館員證徽記與當前等級。
5. 閱覽室選輯與館務室頁腳。

## nav

- 頂部：館徽＋館員證（個人等級）＋檢索。
- 側部（桌面）：排架直欄——十卷宗依三色分區陳列，密室卷宗鎖樣呈現。
- 底部（390）：抽屜式導航——大廳／卷宗／登記簿／養成梯四個抽屜，下拉開啟。

## mobile

390 寬以「卷宗卡抽拉」為核心：卷宗排架橫滑瀏覽，點按抽出一份卷宗卡（全螢幕閱讀，上推歸檔關閉）；登記簿為直式日更清單；養成梯為直式階梯卡序，答題升等後新密室開鎖動畫；抽屜導航拇指可及。

## visual

- 色區：展廳近黑基底＋射燈光斑；古卷宗暖金牛皮紙、今卷宗冷藍金屬櫃、未來密室紫黑雷射防偽光；等級徽記為銀灰。
- 字階：卷宗標題用編號風 24px，內文 17px 明體，引註小字 13px。
- 動效三層：L1 開館亮燈開場（僅首訪）；L2 射燈跟隨（hover／觸控時光斑微移）；L3 卷宗內證物圖逐件顯影（捲動觸發）。無粒子系統，全 CSS。

## rebuild

1. 殼：大廳排架＋卷宗路由＋密室鎖控資料層。
2. 模板：卷宗頁（厚文＋引註格式）、登記簿頁、考核卡模板。
3. 開蒙：養成梯資料層（等級定義、考核題庫）、解鎖與密室聯動。
4. 內容：十卷宗厚文與證物圖整備、閱覽室選輯機制。
5. 上線閘：卷宗引註與 CC BY 4.0 標示覆核、內容零政治覆核、減動效與館務室頁。

## risk

1. LCP：亮燈開場與射燈光斑若用大圖或濾鏡堆疊，首屏造價高——射燈以 CSS 漸層實現，文字先渲染。
2. 制度感門檻：「檔案館」對輕量讀者偏嚴肅，30 秒理解靠開場旁白撐，若旁白失手則 D1 失分。
3. 內容厚度高壓力：卷宗體例要求出處與證物，內容生產成本為十案之最，上線閘須設「先開五宗再開館」的分批策略。
