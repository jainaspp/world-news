# G10 · 雙軌進度橋

**結論：** 序章之後用兩條互不寫入的進度軌接住回訪者：文明軌只記讀到哪一卷，開蒙軌只記下一課；今日切片是文明軌的腳註。三卷不設鎖。

## id

G10

## title

雙軌進度橋

## one_liner

序章之後分文明軌與開蒙軌，兩軌進度不相通，切片只做文明軌腳註。

## sitemap

兩軌都在首頁，不新增進度頁，不合併儲存鍵。

- `/#hero` 全螢幕序章
- `/#track-civ` 文明軌：記錄上次停在卷一或卷二；連結回 `/civilization/chronicle/#ch-ancient` 或 `#ch-now`。卷三是章門，不記完成百分比，連結仍是 `#ch-future`，再去 `/civilization/#future`
- `/#track-learn` 開蒙軌：只讀既有 `wn.edu.progress.v1`，空狀態去 `/learn/zh/` 第一課。課文、解鎖、十二門仍只在 `/learn/`
- `/#slice` 放在文明軌腳註，不放在兩軌之間，也不放進開蒙軌
- `/#monitor` 在文明軌腳註之前，獨立於未來章門
- `/civilization/` 與宇宙、地球、起源、技術、城市維持；起源不因為「進度」再出現一次
- 導讀、週報、分析、專題在「更多」，可由切片腳註進入
- 不開 `/progress/`，不開 `/civilization/future/`

## home_wire

1. **首屏（Hero）：** 全螢幕宇宙演化，宅幽默只在旁白。結尾不說「你的等級」，只說「長河與課堂各記各的。」
2. **第二屏：** 文明軌卡片 → 監測鐘 → 切片腳註。然後是一條至少 24px、不可點的間隔，寫「兩條線不相通」。然後才是開蒙軌卡片。
3. **文明軌內容：** 卷名、時代一句、「繼續閱讀」。沒有百分比，沒有分數，沒有鎖。首次沒有記錄時，顯示三卷並預選「今」的說明，三卷都可點。
4. **開蒙軌內容：** 「下一課」或空狀態「從漢語與文字第一課開始」。不顯示新聞標題。歷史之門維持現有定位：時間軸在編年，不在這裡重寫。
5. 十階只在進入編年後出現。厚文在長頁；懶人包在腳註的既有列。

## nav

- **頂欄：** 品牌、搜尋、深淺色、四主欄。兩軌不取代頂欄。頂欄「開蒙」去 `/learn/` 地圖，不只去「下一課」，避免回訪者看不到其餘的門。
- **底欄：** 品牌句、CC BY 4.0、RSS、合規頁。
- 文明軌的卷名與編年跳卷一致。不把開蒙課名寫進文明軌。

## mobile

寬 390。兩軌直排，中間間隔整行可讀、不可點，高度至少 44px，防止誤觸到另一軌。軌內主按鈕至少 44px，與腳註標題的距離至少 8px。進度不使用橫向步驟條。無腳本時兩軌都顯示靜態入口：文明軌列出三卷，開蒙軌連到 `/learn/`，不出現空白。記錄只存在客戶端，不改變伺服器 HTML 的連結集合。不固定任一軌。

## visual

- **色區：** 文明軌內的卷用暖金、冷藍、紫黑發光飾線。開蒙軌整軌只有紙與墨，不加卷的三色，以免看起來像第四卷。切片腳註用冷藍「今」字標。監測不用紅。
- **字階：** 軌名一級，狀態句二級，全部 ≥12px。不顯示「87%」這類細字進度環。
- **動效：** 重，序章。中，無。輕，無；進度不做成會走的條。reduced-motion 不影響兩軌，因為兩軌沒有動畫。禁 gsap、lenis。

## migration

1. **保留：** `LEARN_PROGRESS_KEY` 的鍵名與語意、開蒙解鎖規則、三卷全部可讀、未來章門、監測與未來分離、#248 契約、五頁資產。
2. **改：** 首頁第二屏改為兩軌加腳註。文明軌若要記「上次的卷」，用另一個客戶端鍵，例如只存 `ch-ancient` 或 `ch-now`，不寫入開蒙鍵，也不記未來百分比。
3. **砍：** 把新聞閱讀進度、開蒙課進度與文明卷進度合成一條的做法。也砍掉用解鎖擋住三卷正文的想法；解鎖只存在於開蒙。
4. **遷移成本：** 首頁一 PR，全站閘。儲存鍵的讀寫可跟模板分 PR，但只要改到首頁 DOM 就是全站閘。測試斷言兩個鍵互不讀取，且未來章的 HTML 仍不含監測註。

## risk

1. **閘：** 兩軌若在 390 並排，間隔會消失，按鈕會小於 44px。驗收必須是直排加大間隔。客戶端寫入不得造成版面跳動。
2. **LCP：** 進度若等客戶端脚本才畫出主按鈕，無腳本與慢脚本會讓第二屏空白。伺服器先輸出三卷與開蒙入口，腳本只更新「繼續」的目標。文明頁 LCP 目標 ＜2.5s，不改該頁。
3. **內容厚度：** 進度卡容易取代正文。文明軌不放課文，開蒙軌不放新聞；厚文與懶人包仍在原頁，切片腳註保留標題列。兩軌都不放廣告；過審前不插腳本。進度用「上次的卷／下一課」表達，不用偽精確百分比。
