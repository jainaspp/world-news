資訊架構以 [G01 原文](../free/grok/P01.md) 與 [領獎台](../synthesis/PODIUM.md) 為準。銀、銅兩案只寫在文末的變體，不與主幹並列競賽。

## 1. 鎖定產品句

文明編年史是一卷可讀完的長文。古、今、未來是同一篇裡的三段，分別以暖金、冷藍、紫黑標出。今日是書籤上的薄層，開蒙是頁緣旁註。兩者都不做站皮，也不拆成另外兩個網站。

讀者在三十秒內應能指出四件事：

| 問題 | 答案落在 |
|------|----------|
| 這是什麼品牌 | 字標「文明編年史」 |
| 主軸是什麼 | 這一卷的三段時間 |
| 開蒙在哪 | 「旁註」 |
| 今日在哪 | 「書籤」 |

版面上不以「新聞」二字做欄名。字標不寫今日、不寫旁註、不寫卷次以外的產品線。

互斥點沿用 G01：主物件是單一文檔，卷只是文內錨點。

## 4. 導覽

### 桌面（寬 1280）

- 頂列：字標回首頁；卷一、卷二、卷三；旁註；書籤。
- 開場進行時頂列仍在，並有「跳過開場」。
- 左欄只在閱讀時出現，列出當前卷的章名。點章即在同卷內移動。
- 右頁緣只在卷二著陸區放三條已開旁註，不跟著每一章黏住，也不蓋住段落。
- 底列：搜尋、授權、關於。

### 窄屏（寬 390）

主手勢只有直向捲動。頁面本身不橫移。

- 頂列只留字標與「卷」。「卷」打開三行，每行高度至少 44px，卷名全文可見：卷一・古、卷二・今、卷三・未來。
- 章名改為標題下方的一列橫向晶片。晶片列不固定在頂列之下，避免兩條固定列夾住正文。晶片列內部可以橫移，不得把整頁帶動左右晃。
- 書籤與旁註是卷中的區塊，不用懸浮鈕蓋住段落。
- 跳過開場後，焦點落在 h1。h1 即字標「文明編年史」，由伺服器送出的 HTML 帶出。
- 系統要求減少動效時，七拍改為七張靜態句子，不載入畫布。

底列在窄屏改為直向文字鏈：搜尋、授權、關於。不用四枚籤標取代「卷」。

## 5. 首頁拍子

順序鎖定如下。線框見 [WIRE-HOME.md](WIRE-HOME.md)。

1. 首屏字標「文明編年史」，副題「一卷，三段時間」。h1 在伺服器送出的 HTML 內。
2. 開場七拍：奇點、對聲響的誤認、原子湯、第一批恆星、恆星撒下的元素、會下雨的藍石、故事交到讀者手上。可跳過。旁白用書面語，本藍圖不預寫逐拍台詞。
3. 跳過或演完後，卷軸停在卷二扉頁。扉頁三行：本卷是「今」；向上為「古」；向下為「未來」。
4. 卷二首章前兩段，證明此處有正文。
5. 書籤條，標「今日切片」，連到 `/cut/`。當日沒有可對照的材料時，寫「今日沒有可對照的切片」。
6. 頁緣三條已開旁註，連到 `/margin/`。
7. 卷二卷末才印停留刻度：寫定的分與秒、資料日期，以及「此數不走動，亦非預報」。
8. 頁尾授權行。

閱讀順序（無障礙樹與寬 390 的直向區塊）就是這八拍。寬 1280 只把第 6 拍改掛右頁緣，與扉頁至書籤同一視區，不另做一屏。

卷一在文書裡位於卷二之上，卷三在卷二之下。首頁停點是卷二，不是把卷一再插進開場與卷二之間。

## 6. 今日薄層

「今日薄層」是產品角色名，只出現在藍圖與評分文件，說明新聞永不做站皮。讀者看見的字是「書籤」與「今日切片」。

| 規則 | 鎖定 |
|------|------|
| 角色 | 插頁式薄層。不是首頁皮膚，不是字標，不是卷名 |
| 入口 | 卷二著陸區的書籤條，連到 `/cut/` |
| 日期 | `/cut/{date}/` 只在該日有可對照材料時才有正文 |
| 空狀態 | 固定句：「今日沒有可對照的切片」 |
| 欄名 | 不出現「新聞」 |
| 索引 | 切片與空章都不索引 |
| 廣告 | 切片不放廣告，未設定的版位不留空框 |
| 場館與地標 | 只可作某一章的案例，不升為卷名，也不鋪成薄層的版頭 |
| 與刻度 | 薄層不顯示停留刻度，不借用刻度做當日標題 |

既有導讀、懶人包、當日頁與單篇，都不是這條新路由的契約。日後若把某一則收進薄層，是另一次內容決定，不是整站改名。見 [ROUTES.md](ROUTES.md)。

## 7. 開蒙（旁註）

開蒙是獨立側線，不是第四卷，也不寫進停留刻度。

- 讀者入口名叫「旁註」，總目在 `/margin/`。
- 第一期三門各一葉。課文未通過合規審讀前，葉頁不索引，頁上只寫「這一葉尚未撰成」，不寫假大綱。
- 其餘九門在總目中標「尚未開啓」。總目可以列出名稱，不做成可進入的空課。
- 旁註葉不放廣告。
- 由淺入深的下一級是這條側線日後的容量，不是第一期線框。第一期不畫進度、不畫關卡、不畫解鎖。
- 卷內右頁緣只放三條已開的門。未開的九門不出現在卷中，只出現在總目。

## 8. 停留刻度（監測鐘）

定性讀數，印在卷二卷末。不放在字標旁，不放在開場上，不放在今日切片。

- 數字由編輯寫定分與秒，並標資料日期。
- 固定句：「此數不走動，亦非預報。」
- 頁面不逐秒更新，沒有倒數，沒有「剩餘」。
- 沒有編輯寫定的數字時，卷末不印刻度，不用 `00:00` 填充。
- 線框裡的數字位寫成「〔編輯寫定的分與秒〕」與「資料日期：〔編輯填寫〕」。這是空位，不是測量結果。

允許的句子形態：

- 「停留刻度由編輯寫定。」
- 「資料日期：〔編輯填寫〕。」
- 「此數不走動，亦非預報。」

不允許：逐秒跳動、倒數、最後若干秒、沒有資料日期的精確秒數、用刻度暗示災變。
