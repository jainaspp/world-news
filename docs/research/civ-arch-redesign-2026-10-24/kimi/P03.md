# K03 · 監測中控（鐘錶儀表式）

> **結論先行：** 把藍本第 5 條允許的監測鐘從配角升為首頁樞紐——首頁是一間「人類處境中控室」：監測鐘居中，三卷化作圍繞鐘面的弧形時間環，`#slice` 是「今日讀數」面板。十案之中視覺辨識最強、首屏記憶點最高；代價是鐘的表述必須死守「隱喻、非偽精確」紅線，文案審查要列入三大閘，且深色中控與古暖金色區的調和需要刻意設計。

- **id:** K03
- **title:** 監測中控·鐘錶儀表

## home_wire

1. **首屏：** BBT 式幽默開場＋全螢幕宇宙演化動畫（首幀 poster 保 LCP）。
2. **第 2 屏：** 中控室——監測鐘大圖（距午夜式隱喻，文字級表述如「午夜前三分鐘的隱喻」，禁止秒數倒數），鐘面外圈是三卷弧環：古弧（暖金）、今弧（冷藍）、未來弧（紫黑發光），點弧段進對應卷。
3. **第 3 屏：** 今日讀數 `#slice`——三則切片＋若干指標卡（沿用既有市場／警告類 API 的呈現方式，文明視角選題）。
4. **第 4 屏：** 開蒙入口卡＋方法學連結（「鐘怎麼看」連 `/data/`）。

## nav

- **頂欄：** wordmark｜中控（首頁）｜三卷｜編年｜開蒙｜切片。
- **底欄：** 指標來源與方法學（`/data/`）、三卷×十階索引、CC BY 4.0、關於。

## mobile（390）

- 鐘縮為頂部 sticky 小錶盤，觸控區 ≥44px，點錶盤回中控。
- 弧環改為三段橫滑卷卡（古／今／未來各一卡），卡寬不溢出視口。
- 今日讀數面板直排；指標卡兩欄格，間距 ≥12px。
- 指針微動只用 CSS transform，無 JS 動畫庫。

## visual

- **色區：** 中控底色深（不屬任何一卷的中性深藍黑），三卷色全部交給弧環段與卷卡呈現——色彩歸卷、不歸背景，避免深色中控吞掉暖金。
- **字階：** 鐘面數字級大字（敘述句 24–28px）／節題 20–24px／正文 16–17px。
- **動效層級：** 重＝Hero 宇宙動畫；中＝鐘指針微動；輕＝弧段點亮、讀數卡進場。

## migration（相對現況）

1. **保留：** 五厚頁、chronicle、既有 `/data/` 與各類指標 API。
2. **改：** 首頁殼重做為中控；新聞模組降為「今日讀數」面板。
3. **新增：** 監測鐘組件（僅首頁使用，紅線：不入 future 正文模組）。
4. **砍：** 首頁新聞皮。
5. **成本：** 中控組件新寫一份；資料層幾乎零新增（複用既有 API），可分「鐘組件→首頁殼」兩個 PR。

## risk（Top 3）

1. **偽精確紅線：** 鐘一旦出現秒倒數或假精度即觸藍本第 5 條禁令——對策：只做文字級隱喻表述，方法學全文公開於 `/data/`，鐘文案列入三大閘審查項。
2. **色區衝突：** 深色中控底與古暖金區可能互相吃掉辨識度——對策：卷色只上弧環與卡面，底色保持中性，D5 自查逐卷截圖。
3. **D1 產品清晰：** 新訪客看到一隻鐘未必知道這是文明編年站——對策：鐘下固定一句產品句＋三卷弧環標籤常駐，30 秒認知測試列入閘前自查。
