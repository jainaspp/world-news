# K02 · 三門分卷（門戶子站式）

> **結論先行：** 首頁是一座門廳——BBT 開場與宇宙動畫收束成三扇卷門，古、今、未來各自擁有半自主的「卷子首頁」與完整色區系統；`#slice` 是門廳裡的一條今日帶，開蒙是第四扇獨立門。十案之中 D2 軸完整性最直觀、各卷可獨立迭代上閘；代價是三套卷頁模板，新增工作量十案最大，靠「單一模板＋卷配置檔」壓住成本。

- **id:** K02
- **title:** 三門分卷·門戶子站
- **one_liner:** 一座門廳三扇門，古、今、未來各是一個可獨立演化的子站。

## sitemap

```

/civilization/             三卷總覽（門的索引版，文字導向）
/civilization/chronicle/   編年正文（以 ?vol=1|2|3 提供卷視圖，不開新路由）
/civilization/cosmos/      卷一門後厚頁
/civilization/earth/       卷一門後厚頁
/civilization/origins/     卷一門後厚頁（#248 唯一 origins 入口不變）
/civilization/tech/        卷二門後厚頁
/civilization/city/        卷二門後厚頁
/learn/                    開蒙（第四扇門，獨立產品線）
新聞舊路由                  保留為切片來源，不進門廳
```

未來仍不開 `/civilization/future/`：卷三門的目標頁是編年 `?vol=3` 視圖＋`#future` 章門。

## home_wire

1. **首屏：** BBT 式幽默開場＋全螢幕宇宙演化動畫，動畫尾聲凝固成三扇門的視覺。
2. **第 2 屏：** 三門並排——每門帶卷色、一句卷語、該卷十階刻度預覽（卷一 1–4／卷二 5–7／卷三 8–10）。
3. **第 3 屏：** 今日帶 `#slice`——細橫帶三則，標明「軸上今日切片」。
4. **第 4 屏：** 監測鐘（隱喻式、文字級，無秒倒數）＋開蒙門（`/learn/`，不混入三門行列，視覺上自成一區）。

## nav

- **頂欄：** wordmark｜卷一·古 ▾｜卷二·今 ▾｜卷三·未來 ▾｜編年｜開蒙｜切片。三個卷下拉列出該卷的十階與厚頁，等於把總覽摺進頂欄。
- **底欄：** 四欄——卷一、卷二、卷三、開蒙；另起一行 CC BY 4.0 與切片來源連結。

## mobile（390）

- 三門直排全寬卡，每卡高 ≥88px，點擊區整卡可觸。
- 頂欄卷下拉改為 bottom sheet，選項行高 ≥44px。
- 今日帶橫滑三卡；開蒙門全寬 48px 按鈕。
- 卷色全出血背景，390 下一眼可辨自己站在哪扇門前。

## visual

- **色區：** 三卷三色直接漆在門上——暖金門、冷藍門、紫黑發光門；卷頁繼承門色，進門即入色場。
- **字階：** 門題 26–30px／卷頁節題 20–24px／正文 16–17px。
- **動效層級：** 重＝Hero 宇宙動畫（僅首屏）；輕＝門 hover／tap 微光、門廳→卷頁色場繼承過渡。無 gsap／lenis。

## migration（相對現況）

1. **保留：** 五厚頁與 chronicle 正文；#248 Wave0 行為不動。
2. **改：** `/civilization/` hub 變門索引（文字版門廳）。
3. **新增：** 卷視圖——由 chronicle 擴展 `?vol=N` 視圖實現「卷子首頁」，不開新路由，規避 `/civilization/future/` 紅線。
4. **砍：** 首頁新聞皮（今日帶承接）。
5. **成本：** 三套卷頁是最大新增；以單一模板＋三份卷配置（色、卷語、階段清單、厚頁卡）實作，分「門廳→卷視圖」兩個 PR 上閘。

## risk（Top 3）

1. **分工模糊：** 卷頁與 chronicle 可能內容重疊——對策：卷頁只做導流與卷級摘要，正文一律在編年。
2. **D1 資訊量：** 三門首屏每門只有一句話，新訪客可能看不出「這裡是文明編年」——對策：門上加產品句、門上刻十階預覽，30 秒測試列入閘前自查。
3. **維護成本：** 模板×3 長尾維護——對策：單模板＋卷配置檔，禁止三份手寫 HTML 漂移。
