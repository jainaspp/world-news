# K06 · 章回書頁（書籍目錄式）

> **結論先行：** 把整站當一本日日續寫的書——首頁是書封＋總目錄，chronicle 是書身（「卷—回」兩級，天然對應三卷十階），`#slice` 是夾在「今」卷書脊的今日號外，`/learn/` 是附設學堂（另一本書，互不通頁）。十案之中編輯感與 D7 內容承載最高，厚文、懶人包、切片各得其所；代價是互動性最弱，手機快速消費場景要靠號外卡與目錄前置補救。

- **id:** K06
- **title:** 章回書頁·書籍目錄
- **one_liner:** 文明編年史不是一個網站，是一本日日續寫的書。

## sitemap

```
/                          書封＋總目錄（Hero 封面＋三卷回目＋號外夾頁）
/civilization/             總目錄（卷—回—階對照表）
/civilization/chronicle/   書身（三卷十階正文；#248 table scroll 保留為「附表」行為）
/civilization/cosmos|earth|origins|tech|city/   插圖卷（五厚頁保留）
/learn/                    學堂（獨立產品線，另一本書）
新聞舊路由                  號外料房，保留不進書封
```

未來不開新路由：卷三回目收於 `#future` 章門，正文在書身未來段。

## home_wire

1. **首屏：** 書封——全螢幕宇宙演化動畫為封面底，BBT 式幽默題辭印在封面上（首幀 poster 保 LCP）。
2. **第 2 屏：** 總目錄——三卷章目並列，每卷列出回目與十階刻度（卷一 1–4／卷二 5–7／卷三 8–10）。
3. **第 3 屏：** 今日號外 `#slice`——報章夾頁造型，三則標題＋原文連結，報眉印「軸上今日切片」。
4. **第 4 屏：** 扉頁印章——監測鐘以藏書章式呈現（隱喻、文字級，無秒倒數）＋學堂入口（`/learn/`）。

## nav

- **頂欄：** wordmark｜目錄｜書身（編年）｜學堂｜號外。
- **底欄：** 版權頁式編排——CC BY 4.0 授權、卷索引、五厚頁直連、關於。

## mobile（390）

- 總目錄直排回目，每行高 ≥44px，卷色書籤帶貼左緣。
- 號外卡橫滑；書身閱讀寬度鎖 34–38 字／行。
- sticky「回頂目錄」鈕 ≥44px；翻頁式進場動效 ≤200ms，無動畫庫。
- 印章式監測鐘觸控區整章可點，連到方法學說明。

## visual

- **色區：** 紙感米白底＋三卷色書籤帶（金／藍／紫）；卷三頁籤帶發光邊，紫黑只用在書籤與章門，不把整頁刷黑。
- **字階：** 書籍式——卷題 28px／回目 18–20px／正文 17px、行高 1.8；標題用系統襯線栈，不載 webfont（保 LCP）。
- **動效層級：** 重＝封面動畫（僅首屏）；輕＝翻頁進場、書籤帶隨卷變色。

## migration（相對現況）

1. **保留：** 五厚頁（重新定位為插圖卷，內容不動）。
2. **保留：** chronicle 骨架——#248 的三卷疊十階天然就是「卷—回」，table scroll 保留為附表。
3. **改：** 首頁書封化、`/civilization/` 目錄化；新聞模組降為號外夾頁。
4. **砍：** 首頁新聞皮（號外承接其更新頻率與連結）。
5. **成本：** 低中——主要是皮層與文案層，chronicle 與五厚頁骨架不動；分「書封→目錄」兩個 PR。

## risk（Top 3）

1. **手機速讀不友善：** 書籍隱喻重沉浸、輕掃讀——對策：號外卡與目錄都放前兩屏，390 下三屏內可達任何一卷。
2. **LCP：** 襯線字與紙感材質易增重——對策：只用系統襯線栈與 CSS 紙感，不載字體與紋理圖，閘內實測 civ＜2.5s。
3. **品牌反噬：** 「號外」本質仍是新聞，造型太搶會讓書封變報攤——對策：號外版面積恆小於書封，文案固定標明「軸上今日切片」。
