# K05 · 卡池星圖（Bento 模組式）

> **結論先行：** 首頁是一副 bento 卡池——Hero 卡、三卷卡、十階刻度長條卡、`#slice` 卡、監測鐘小卡、開蒙樹卡，全部是同一規格的可重組模組；手機上卡池自動解體為直列與橫滑卡組。十案之中模板成本最低、重排彈性最大，日後加模組不用改版；代價是敘事感十案最弱，必須靠固定卡序（古→今→未來）與十階長條卡把主軸「畫」回來，否則 D2 失分。

- **id:** K05
- **title:** 卡池星圖·Bento 模組
- **one_liner:** 三卷、切片、鐘、開蒙統一成一副可以重排的卡。

## sitemap

```
/                          首頁＝卡池（Hero 卡＋六張功能卡）
/civilization/             三卷總覽
/civilization/chronicle/   編年正文（#248 行為不變）
/civilization/cosmos|earth|origins|tech|city/   五厚頁保留
/learn/                    開蒙（獨立產品線）
新聞舊路由                  保留為切片後台
```

未來不開新路由：卷三卡即 `#future` 章門卡，指向編年未來段。

## home_wire

1. **首屏：** Hero 卡——BBT 式幽默開場＋全螢幕宇宙演化動畫，佔滿首屏（首幀 poster 保 LCP）。
2. **第 2 屏：** bento 區（桌面 12 欄格，卡序固定）——卷一大卡（暖金，4×2）＋卷二中卡（冷藍，4×2）＋卷三章門卡（紫黑發光，4×2）。
3. **第 3 屏：** 十階刻度長條卡（12×1，三卷色帶分段，階點可點）＋`#slice` 卡（今日三則，標明「軸上今日切片」）＋監測鐘小卡（隱喻式，無秒倒數）＋開蒙樹卡（`/learn/` 入口）。
4. 卡數上限七張，每卡一句話一個行動，禁止卡上疊卡。

## nav

- **頂欄（精簡）：** wordmark｜編年｜開蒙｜切片。
- **底欄（補齊）：** 因首頁已是卡池，底欄放純文字全站索引——三卷×十階、五厚頁、學科樹、CC BY 4.0，保 SEO 與無 JS 可用性。

## mobile（390）

- bento 自動解體：三卷卡轉為一組橫滑（等權重三卡），其餘直列。
- 十階長條卡轉為直向十格 stepper，每格高 ≥44px。
- 卡圓角 16px、間距 12px，390 寬下功能卡兩欄格不溢出。
- 全部卡即按鈕：整卡可點，最小觸控面遠大於 44px。

## visual

- **色區：** 卷色嚴格只上對應卡面——金卡、藍卡、紫黑發光卡；底色中性，卡池像星圖：深色底上三色卡各自發光。
- **字階：** 壓縮為兩級半——卡題 20–24px／卡內一句話 15–16px／正文頁 16–17px。
- **動效層級：** 重＝Hero 卡動畫（僅首屏）；輕＝卡 hover 浮起、進場 stagger（純 CSS，無 gsap／lenis）。

## migration（相對現況）

1. **保留：** 五厚頁、chronicle 及 #248 全部行為。
2. **改：** 首頁殼改 bento 格；新聞模組降為一張 `#slice` 卡。
3. **改：** 現有 hub 模組逐張改皮成卡，規格統一（一句話＋一個行動）。
4. **砍：** 首頁新聞皮；首頁所有非卡式遺留模組。
5. **成本：** 十案最低——多數卡由既有模組改皮而來；單一 PR 可完成，閘壓力小。

## risk（Top 3）

1. **D2 敘事弱：** 卡池本身不講先後——對策：卡序永遠古→今→未來，十階長條卡充當視覺軸，卷題字級大於功能卡。
2. **D1 大雜燴：** 卡一多首屏即失焦——對策：卡數硬上限七張，每卡一句話，30 秒認知測試列入閘前自查。
3. **D7 廣告位：** 卡格與未來 AdSense 版位易衝突——對策：審查凍結期零腳零框；版位只預留槽位規格（不出灰框），解除後才填。
