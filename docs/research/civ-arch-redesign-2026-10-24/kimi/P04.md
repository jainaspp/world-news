# K04 · 三卷切換（一頁三面 Tab 式）

> **結論先行：** Hero 之下放一條 sticky 三卷切換列，首頁下半整面隨卷別重繪——色場、卷語、十階刻度、精選卡一次換；`#slice` 是恆常欄不隨切換消失，監測鐘只住在「今」面。本質是「一頁三面」：首載只渲染「今」面，古與未來兩面按需取得。十案之中互動感最強、首載最輕；代價是切換狀態的深連結與 SEO 分工要設計清楚，否則古、未來兩面對爬蟲近乎隱形。

- **id:** K04
- **title:** 三卷切換·一頁三面
- **one_liner:** 一個首頁三種卷色，切換列一按就換一個世界。

## sitemap

```
/                          首頁：Hero＋卷切換列＋卷面（?vol=1|2|3 或 #vol-N 狀態，預設「今」）
/civilization/             三卷總覽（三卷連結的穩定落地頁，SEO 主體）
/civilization/chronicle/   編年正文（#248 行為不變）
/civilization/cosmos|earth|origins|tech|city/   五厚頁保留
/learn/                    開蒙（獨立產品線）
新聞舊路由                  保留為切片後台
```

未來不開新路由：「未來」面的章門指向 `#future` 與編年未來段。

## home_wire

1. **首屏：** BBT 式幽默開場＋全螢幕宇宙演化動畫；動畫本身依古→今→未來順序播放，先講一次完整主軸。
2. **第 2 屏：** sticky 卷切換列（古｜今｜未來三格，各 ≥44px）＋當前卷模組組：卷語、該卷十階刻度、精選卡、對應厚頁卡。
3. **恆常欄：** `#slice` 今日切片（桌面右欄／手機第 2 屏末段），不隨換面消失，標明「軸上今日切片」。
4. **卷面差異：** 監測鐘小件只在「今」面出現；「未來」面末端是 `#future` 章門；開蒙入口為三面共通固定位。

## nav

- **頂欄：** wordmark｜編年｜開蒙｜切片——卷切換已內建於首頁，頂欄不重複三卷，避免兩套互相打架的卷導航。
- **底欄：** 三卷×十階全索引、五厚頁、`/learn/`、CC BY 4.0。

## mobile（390）

- 切換列 sticky top，三格 segmented control，每格寬 ≥110px、高 ≥44px。
- 換面用色場 fade＋模組位移，時長 ≤250ms，不引動畫庫。
- `#slice` 卡橫滑；卷面模組直排；全部可點區 ≥44px。
- 換面前後保留滾動位置記憶，返回舊卷不從頭滾。

## visual

- **色區：** 每面嚴格單一卷色——「古」面全暖金、「今」面全冷藍、「未來」面全紫黑發光；切換列本身用中性色，當前格填入卷色。
- **字階：** 卷題 26–30px／節題 20–22px／正文 16–17px。
- **動效層級：** 重＝Hero 動畫（僅首屏）；輕＝換面 fade、模組位移、切片卡進場。

## migration（相對現況）

1. **保留：** 五厚頁、chronicle 及 #248 全部行為。
2. **改：** 首頁殼＋切換列新寫；新聞模組降為恆常 `#slice` 欄。
3. **新增：** 卷面狀態層（`?vol=`／hash 雙寫入，支援深連結與返回鍵）。
4. **砍：** 首頁新聞皮。
5. **成本：** 中——三面模組多由現有 hub 模組改皮重組，真正新增是切換狀態層；一個 PR 可完成，但建議拆「殼＋今面→古／未來面」兩個 PR 降閘壓。

## risk（Top 3）

1. **SEO／深連結：** 三面共用 URL 會讓古、未來內容對爬蟲不可見——對策：三卷核心連結全部存在於 `/civilization/` 總覽，首頁三面定位為增強層而非唯一入口，`?vol=` 頁 canonical 指 `/`。
2. **CLS：** 換面佈局高度差造成跳變——對策：三面模組槽位統一骨架高度，換面先出骨架再填內容。
3. **曝光不均：** 預設「今」面令古卷曝光偏弱——對策：Hero 動畫順序播完三卷、切換列常駐可見，並在「今」面尾部放「上一卷」導引卡。
