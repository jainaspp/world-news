## 1. 一句定位

> **文明編年史係一把尺：讀者 30 秒內看見自己企喺 138 億年時間軸嘅邊一格，並且識得將今日任何一條新聞，掛返落古、今、未來同一條線上。**

## 4. 內容策略

**每章最小可讀厚度**（CJK 正文字數，唔計來源表同 chrome）：

- 卷一：每節維持現有約 120–180 字＋里程碑清單。**古唔再加厚**；只做邊界修正（04/05、06/07 相鄰節各加一句銜接句，避免斷裂感）。
- 卷二：每節加厚到 ≥250 字。08 補電子支付前史、09 補 2010 年代（移動／雲／AI 起步）、10 全新 ≥400 字（四條主線：AI 通用化／數字貨幣形態／生命科學工具／氣候壓力，每線一里程碑一來源）。
- 卷三：每域 ≥200 字，沿用 future.ts schema 四件（機制／減緩／不確定／資料日期），唔發明新欄位。

**產物／推動力／問題索引重組**：

- `CivProduct`／`CivDriver`（contract.ts 既有欄位）唔再按階平鋪展示，渲染層按「卷」聚類；資料層欄位唔變。
- `questions.ts` 問題索引加三卷分組標（古／今／未來）；href 驗證集加入編年頁新位置嘅 `future-*` 錨（見 P1-4）。
- 「本世紀」節用**切片掛點**格式收 4–6 條近史新聞錨：日期＋標題＋鏈，唔寫評論、唔寫導讀。呢個係「今」加厚嘅正路——今日新聞有落地格，而唔係編年變新聞牆。

**點加厚「今」同「未來」而唔淨係堆古**：卷一七節字數封頂（每節 ≤180 字硬上限寫入 data 註釋），新增篇幅配額全部畀卷二卷三；成功標準用字數比例鎖死（第 8 節）。

## 6. 視覺／動效契約

**對齊墨紙**：基底 `#161c24`＋紙感，禁整站換純黑；對比達 WCAG AA（正文 4.5:1、大標 3:1），亮暗兩模式各自成立。

**chronicle 頁允許嘅 motion model**（全部沿用現有機件，零新增依賴）：

1. `civ-reveal` IntersectionObserver 淡入（既有；boot script 模式唔變）。
2. `civ-progress` 閱讀進度條（既有）。
3. 紙印 seal 序號：十階 seal 保留；卷章另用「卷一／卷二／卷三」紙印，唔用數字同十階爭。
4. **新增唯一一樣**：卷章扉頁——靜態版式（卷名＋一句卷語＋本章 chips 目錄），純 CSS，零 JS、唔做 sticky。

**禁區**：

- 唔加 gsap／lenis／任何 scroll-driven animation 庫；唔改 BBT Hero canvas。
- 卷章扉頁同卷首監測鐘唔做 sticky／fixed（避免同 CTA、BackToTop 搶層，前車之鑑係手機四層重疊事故）。
- `prefers-reduced-motion` 下全部動效降靜態（既有 boot 邏輯沿用，唔准新寫唔降級嘅動效）。
- 手機 ≤390px：卷章標題唔准換行重疊、chips 目錄橫滑唔准劫直滑（過 TRAP-V01 全長截圖＋TRAP-V02 碰撞掃描＝0 先算數）。
- 首頁撤咗十圓點帶之後，axis band 只留 spine 一條軸，唔准再雙軸並置。

## 9. 刻意不做（範圍鎖）

1. **唔開新路由**（唔做 `/civilization/future/` 獨立頁）——CF 配額緊張＋每開一路由就多一組閘；卷三住喺編年單頁。

4. **唔做互動時間軸**（拖曳／縮放／WebGL／gsap／lenis），唔改 BBT Hero canvas——手機效能同減動態約束。

6. **唔動新聞 pipeline 業務邏輯、AdSense、sitemap 生成器**——唯一准改係 sitemap description 字串。
7. **唔做英文版／簡體版編年**——產能同合規（s2hk 管道另議），本輪書面繁中一個語種。
