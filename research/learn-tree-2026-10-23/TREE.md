## 3. 解鎖規則（與碼契約對齊）

| 規則 | 說明 |
|------|------|
| **門開／淡** | `LearnSubject.open`：種子三門 `true`；其餘 `false` 只顯示方位句＋回地圖 |
| **葉可讀** | 僅 `open===true` 之門可掛 `LEARN_LESSONS`；淡門禁止假正文 SEO |
| **完成** | 葉頁「本節讀完」→ `completed[]` 寫入 `wn.edu.progress.v1` |
| **下一葉** | 同 L2 下：建議 `prereq`＝前一葉 id；無 prereq 則父 L2 已亮即可並修 |
| **下一門徑（L1）** | 預設：該 L1 下**至少一條 L2 的 ready 葉全完成**，或顯式「本塊讀完」（二選一，CA 實作鎖一種並寫進測試） |
| **跨門** | P0／P1 **不**做「讀完語文才開數學」；萬有地圖並陳，能力樹非單一主線 RPG |
| **重設** | Hub「重設本機進度」清 key；可匯出／匯入 JSON 列 P1 |
| **鎖定文案** | 「尚未開啓之路」；禁止闖關失敗／請先交作業 |

**建議進度形（向前相容）：**

```ts
type EduProgress = {
  completed: string[];      // leaf id，例 "glyph" 或未來 "zh.l3.glyph"
  civPoints?: number;       // 顯示用累計；可自 completed 派生
  updatedAt: string;        // ISO
};
```
