# 開蒙 × 文明｜資訊架構分際

**日期：** 2026-10-23（Asia/Hong_Kong）  
**交付：** `/workspace/research/learn-tree-2026-10-23/IA.md`  
**對齊：** live `/learn/`、`/civilization/*`；edu-tree 02；PP O「開蒙獨立產品線」  
**體例：** 繁中書面｜結論先行｜給設計／CA／站級閘共用

---

## 結論（先行）

1. **開蒙＝能力／知識樹**（`/learn/`）；**文明＝敘事時間軸**（`/civilization/*`）；**懶人包＝今日事件切片**——三線並行，正文不互貼。  
2. **開蒙保持獨立產品線：** 不掛在 `/civilization/` 下；不進文明 stage 資料模型；sitemap／index 策略可與文明不同步（現況 learn **noindex** 至樹夠厚）。  
3. **互薦只走軟鏈：** 葉底 0–2 條「敘事上，見…」；文明頁旁註「系統立基見開蒙・某門」；禁止內嵌整樹或整段互拷。  
4. **導航氣魄＝萬有地圖**，不是選課中心；與 live motto「開蒙——森羅萬象，由一葉始。」一致。

## 1. 讀者問題對照

| 產品線 | 讀者進來問什麼 | 走了之後帶走什麼 |
|--------|----------------|------------------|
| **開蒙 `/learn/`** | 這門知識由淺入深怎麼立？下一葉在哪？ | 可複述的能力階梯＋本機進度 |
| **文明 `/civilization/*`** | 人類／世界如何一路走到這裡？古／今／未來如何排？ | 時間感、編年結構、監測讀數隐喻 |
| **懶人包／今天切片** | 今天這則事件怎麼讀？出處在哪？ | 標題＋出處＋整合說明（不轉載全文） |
| **JD Tech／工具橋** | 哪個工具能動手做？ | 工具卡／Reel 落地（與開蒙 P0 脫鉤） |

**同一詞、兩正文：** 「文字」「星空」「城市」可兩線皆出現；開蒙寫能力，文明寫敘事；只深鏈。

## 2. 路由與物件

### 開蒙

```
/learn/                          Hub＝萬有地圖（12 門門面）
/learn/{subject}/                門頁（開＝葉列表；淡＝方位句）
/learn/{subject}/{leaf}/         葉正文＋「本節讀完」
```

| 物件 | 來源（live） | 備註 |
|------|--------------|------|
| Subject | `LEARN_SUBJECTS` | 12 門閉集；`open` 控制可讀 |
| Lesson／葉 | `LEARN_LESSONS` | 現 3 短箋；加厚見 SAMPLE-LESSONS |
| Progress | `localStorage` `wn.edu.progress.v1` | 零帳號；可重設 |
| 文明點 | 由 completed 派生或欄位 | **顯示-only，不兌換** |

### 文明（對照，不合併）

```
/civilization/                   總覽／軸
/civilization/chronicle/         編年厚頁
/civilization/cosmos|earth|origins|tech|city/
/civilization/#future            未來錨
```

| 物件 | 本質 |
|------|------|
| Stage／編年章 | 時間敘事單元 |
| 監測讀數／末日鐘隐喻 | 文明感裝置；**非**開蒙打卡 |
| 文明榜／註冊（規劃） | 可顯示開蒙累計點；仍不兌換 |

## 3. 頁面模組（開蒙）

### Hub `/learn/`

1. 眉題／H1：開蒙 · 森羅  
2. Motto 一行  
3. 本機進度一句（葉數；可選文明點顯示）  
4. **萬有地圖**：方位圖例＋12 門（`is-open`／`is-locked`）  
5. 底註：敘事見文明軸；今日見懶人包；此處是能力樹  
6. 重設本機進度  

**禁止：** 選課中心、年級表、熱門科排行、廣告腳本（過審前）、假目錄淡門堆 SEO。

### 門頁

- 開：orientation＋方位＋葉卡列表（title／summary）  
- 淡：orientation＋「尚未開啓之路」＋回地圖  

### 葉頁

- 標題＋summary＋正文段落  
- 軟鏈區（≤2）：文明／懶人包  
- 「本節讀完」＋返回門頁  
- 不重複站級長免責；教學預設 CC BY 4.0 可於站級頁說明，葉內不堆疊

## 4. 全域導航位置

| 位置 | 建議 |
|------|------|
| 主 chrome | 「開蒙」鏈 `/learn/`（live 已有）；與「文明」並列，**不**嵌在文明下拉唯一子項裡充數 |
| 首頁 | 可有入口鏈；**勿**塞進 axis-hero 冒充編年一環（測試已約束 hero 不含 `/learn/` 誤植，頁腳／導航可含） |
| 文明頁 | 旁註／延伸：「系統立基見開蒙」；禁止整樹 iframe／巨型目錄 |
| Sitemap | 樹夠厚且 `learnIndexable()` 翻轉前：**不**進 sitemap（與現測一致） |
| Robots | 現況 `noindex,follow`；加厚達標後另開站級閘討論 index |

## 5. 軟鏈契約（唯一合法交叉）

```ts
softLinks?: {
  civilization?: string[]; // 0–2，例 ["/civilization/chronicle/", "/civilization/origins/"]
  explainer?: string[];    // 懶人包路徑或穩定題標
};
```

| 允許 | 禁止 |
|------|------|
| 「敘事上，見文明編年」 | 把編年段落貼進葉 body |
| 「今日相關概念見懶人包」 | 把當日新聞改寫成開蒙正文 |
| 文明頁「見開蒙・漢語與文字」 | 文明 stage JSON 內嵌 EduNode 樹 |
| 完成葉累計文明點（顯示） | 用點數兌換解鎖／去廣告／商城 |

## 6. 視覺與動態

| 項 | 開蒙 | 文明 |
|----|------|------|
| 基調 | 墨紙可重用（深灰 `#161c24`＋紙感） | 古暖金／今冷藍／未來紫黑（軸專用） |
| 動效 | 樹展開 CSS；尊重 `prefers-reduced-motion` | Hero／軸動畫另約三大 model 閘 |
| 時鐘 | **無**倒數打卡 | 監測讀數可有；非開蒙元件 |

重大 landing 動畫加強須經站級合議；開蒙 P0 以清晰地圖為先，不拿「爛動畫」充氣魄。
